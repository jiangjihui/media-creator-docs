# 摄像 · 总览

> 摄像是以「视频」为载体的创作：把想法变成会动的画面、有节奏的声音。它比「影视制作」更大——影视制作（剧情片、纪录片、宣传片等）只是摄像的一种形态；个人 Vlog、口播、短视频、直播等都属于摄像的范畴。本板块按「影视制作 → 视频 → 短视频 → 直播」分组组织，每一篇都尽量「先讲清原理，再给可执行的做法」。

## 建议学习顺序

> 新手建议：**影视制作**——前期策划 → 拍摄 → 剪辑与调色 → 声音设计，把完整流水线走一遍后，再按需进入视频 / 短视频 / 直播分组。
