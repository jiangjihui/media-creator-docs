# 影视制作 · 分组总览

> 本分组属于 [摄像 · 总览](/contents/摄像/README.md)。

> 影视制作是把「一个想法」变成「一支视频」的完整流水线：**前期策划 → 拍摄 → 剪辑与调色 → 声音设计**。它和摄影最大的不同是「时间维度」——摄影定格瞬间，视频讲述过程。本分组按这条流水线组织，每一篇都尽量「先讲清原理，再给可执行的做法」。

> 它建立在前面的摄影板块之上——构图、用光、对焦、曝光这些基础在拍摄篇里会直接复用。如果你还没读过摄影板块，建议先补基础，再看这里。

## 流水线速览

| 环节 | 一句话 | 核心产出 | 对应文章 |
| --- | --- | --- | --- |
| 前期策划 | 想清楚拍什么、给谁看 | 脚本、分镜、预算、排期 | [前期策划](前期策划.md) |
| 拍摄 | 把脚本变成素材 | 画面 + 声音素材 | [拍摄](拍摄.md) |
| 剪辑与调色 | 把素材剪成故事、调成风格 | 成片（画面部分） | [剪辑与调色](剪辑与调色.md) |
| 声音设计 | 让声音有层次、有情绪 | 成片（声音部分） | [声音设计](声音设计.md) |

> 一句话：**前期想得越清楚，拍摄越省事，后期越省心**。这条流水线里，最便宜的改动在前期（改文档），最贵的改动在后期（重拍）。

## 建议学习顺序

> 新手建议：**前期策划 → 拍摄 → 剪辑与调色 → 声音设计**（按真实制作流程走一遍）。
> 如果只做短视频/口播，可先跳「前期策划 + 拍摄」，把素材拍好再回来补剪辑；声音设计不建议跳过——**声音是视频质感的一半**，很多人忽略了它。
