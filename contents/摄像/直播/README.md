# 直播 · 分组总览

> 本分组属于 [摄像 · 总览](/contents/摄像/README.md)。

> 直播是「实时、互动、一次性」的视频形态：不剪辑、不重来，筹备、推流、互动、复盘都和录播不同。它的核心指标不是完播，是**在线人数、互动率、转化**。本分组按「筹备与现场执行 → 互动与话术」组织。

> 它和 [影视制作](/contents/摄像/影视制作/README.md) 的拍摄/声音基础通用——直播也是「画面 + 声音」，只是多了一层「实时推流」和「人」。设备与推流细节可参考设备板块。

## 与相邻形态的区别

| 形态 | 时间性 | 核心指标 | 关键能力 |
| --- | --- | --- | --- |
| 视频 / 短视频 | 录播、可剪 | 完播、播放 | 叙事、剪辑 |
| 直播 | 实时、一次性 | 在线、互动、转化 | 筹备、互动、临场 |

## 建议学习顺序

> 新手建议：**直播筹备与现场执行 → 直播互动与话术**。先把设备和流程跑通不出事故，再练怎么和观众聊、怎么留人转化。
