# 视频 · 分组总览

> 本分组属于 [摄像 · 总览](/contents/摄像/README.md)。

> 视频是「个人内容形态」的创作：Vlog、口播、开箱评测、生活记录、探店——**单人可完成、不需要完整影视工业流程**的普通视频。它和 [影视制作](/contents/摄像/影视制作/README.md)（专业流水线）、[短视频](/contents/摄像/短视频/README.md)（平台分发）、[直播](/contents/摄像/直播/README.md)（实时互动）互补。本分组按「个人内容形态」组织，每一篇都尽量「先讲清原理，再给可执行的做法」。

> 它建立在摄影板块与影视制作的拍摄/剪辑/声音基础之上。如果你还没读过这两个板块，建议先补基础，再看这里的个人创作篇——本分组里的案例会频繁引用它们，不重复造轮子。

## 形态速览

| 形态 | 一句话 | 核心特点 | 难度 |
| --- | --- | --- | --- |
| [Vlog](Vlog从选题到发布.md) | 个人视角的视频日记 | 真实感 > 精致感，人格化 | ★★☆ |
| [口播](口播脚本与镜头感.md) | 对着镜头讲观点/知识 | 信息密度高，靠表达 | ★★☆ |
| [开箱评测](开箱评测流程.md) | 拆新品、讲好坏 | 客观 + 结构化，避坑 | ★★★ |
| [生活记录](生活记录.md) | 碎片化的日常切片 | 叙事弱，氛围强 | ★☆☆ |
| [探店](探店.md) | 去店里吃/玩并点评 | 真实 + 信息交代 | ★★☆ |

> 一句话：**形态之间没有高低，只有适合不适合**。新手建议从 Vlog 或生活记录入手（设备门槛低、容错高），等镜头感和剪辑手感上来，再攻口播和开箱评测。

## 建议学习顺序

> 新手建议：**Vlog / 生活记录 → 口播 → 开箱评测 / 探店**。先练「拍得稳、剪得顺」，再练「讲得清、评得准」。

## 各组文章

| 文章 | 核心问题 | 关键动作 |
| --- | --- | --- |
| Vlog 从选题到发布 | 怎么把日常拍成有人看的 Vlog | 选题、提纲、一人拍摄、剪辑节奏、发布 |
| 口播脚本与镜头感 | 怎么对着镜头把话说清楚、有吸引力 | 脚本结构、镜头感、提词器、录制节奏 |
| 开箱评测流程 | 怎么客观地把一个产品讲明白 | 拍摄清单、评测维度、客观表述 |
| 生活记录 | 怎么把碎片日常剪成有味道的片子 | 素材化、叙事线、留白、配乐 |
| 探店 | 怎么拍好一家店并真实点评 | 踩点、许可、美食拍摄、信息交代 |

→ 拍摄参数可参考 [影视制作 · 拍摄](/contents/摄像/影视制作/拍摄.md) 的口播案例与 [摄影 · 拍摄技术](/contents/摄影/拍摄技术/)；剪辑节奏参考 [影视制作 · 剪辑与调色](/contents/摄像/影视制作/剪辑与调色.md) 的 Vlog 案例；声音参考 [影视制作 · 声音设计](/contents/摄像/影视制作/声音设计.md) 的口播混音。设备选型见设备板块。
