# 短视频 · 分组总览

> 本分组属于 [摄像 · 总览](/contents/摄像/README.md)。

> 短视频是「竖屏 + 快节奏 + 钩子式结构」的内容形态：开头 3 秒钩子、信息密度高、节奏快、完播率优先。它和 [视频](/contents/摄像/视频/README.md)（个人内容形态，可长可短）的区别在于**为平台算法而生**——时长通常在 15 秒到 3 分钟，结构服务于「让人划不走」。本分组按「脚本钩子 → 竖屏拍摄」组织。

> 它和 [影视制作](/contents/摄像/影视制作/README.md) 的拍摄/剪辑基础通用，但更强调「短」和「钩」。基础参数（曝光、对焦、白平衡）仍可参考 [摄影 · 拍摄技术](/contents/摄影/拍摄技术/) 与 [影视制作 · 拍摄](/contents/摄像/影视制作/拍摄.md)。

## 与相邻形态的区别

| 形态 | 时长 | 核心目标 | 结构重心 |
| --- | --- | --- | --- |
| 视频（Vlog/口播） | 数分钟 | 看完、认同 | 叙事/表达 |
| 短视频 | 15s–3min | 划不走、完播 | 钩子/节奏 |
| 直播 | 实时 | 互动、留存 | 互动/转化 |

## 建议学习顺序

> 新手建议：**短视频脚本与钩子结构 → 竖屏拍摄与画面**。先把「钩子和节奏」想透，再练竖屏怎么拍好看。
