# 常用工具链接 · 总览

> 这一页只回答一件事：**站内提到的这些软件、素材、插件，到底去哪下**。按**视频 → 音频 → 图片 → 素材曲库与插件**四类排布，每类只给「工具名 + 官方主域名 + 获取的注意点」。与 [软件 · 总览](/contents/软件/README.md) 的边界照旧——**这里只放链接清单，不做选型对比**；要判断「该用哪个」去软件板块，要下载才回来看这里。本页**只给广为人知的稳定主域名，不给深层 URL**：深层路径会随版本改版失效，主域名几乎不会。信息核对时点：**2026-09**。

## 怎么用这份清单

下载这件事的风险从来不在「找不到」，而在「下错了」——山寨站常常排在搜索结果真官网前面，捆绑安装与假破解是新手丢素材、重装系统的两大来源。

| 检查项 | 靠谱的样子 | 危险信号 |
| --- | --- | --- |
| 域名 | 与官方品牌一致、拼写正确、HTTPS | 多/少字母、奇怪后缀、`.net` 冒充 `.com` |
| 下载入口 | 官网 Downloads 页直接给安装包 | 「高速下载器」「下载助手」先下 exe 再下软件 |
| 安装包 | 体积与官方说明接近 | 体积明显偏小或偏大，安装向导里夹带勾选 |
| 授权 | 官网明码标价或标明开源协议 | 「破解版」「激活器」「注册机」 |
| 校验 | 官方提供校验值或数字签名 | 完全没有校验方式 |

- **先官网，再其他**：搜到结果先确认域名是不是官网，别急着点第一个。
- **安装慢一点**：安装向导每一步都看清，取消不必要的勾选、不装附带的浏览器扩展。
- **警惕「破解」**：所谓激活器往往是木马载体；本站推荐的工具大多有免费或开源替代，见各工具档案。
- **校验是好习惯**：发布方给了校验值或签名就顺手核一下，尤其是装在工作机上的工具。

> 原则：下错工具的代价，远高于多花十分钟核对——轻则重装，重则丢素材。

| OBS | obsproject.com | 开源免费，官网直下；任何「收费代下」都不对 |

> 提醒：下载前先确认「到底该用哪个」——这一页不替你做这个决定，只负责把你送到正确的官网。

| Lightroom Classic | adobe.com | 订阅制，随 Creative Cloud 分发 |
| Capture One | captureone.com | 订阅/买断并存，按品牌有定制版本 |
| darktable | darktable.org | 开源免费，跨平台 |

- **IrfanView 最容易漏装插件包**：主程序装完能看图，但 RAW、PDF 与部分格式的解码能力全在 **Plugins** 插件包里。官网下载页把主程序与插件包分列，两个都装才完整——这一步的遗漏，是「为什么我的 IrfanView 打不开这个格式」最常见的原因。

- **授权条款看一眼**：XnView MP 对商用有单独授权要求，个人免费不等于可以拿去做商业交付。

## 素材、曲库与插件

这一类是本页唯一的**非软件**条目，也是最容易被忽略的一环：工具都下好了，片子的配乐、字体、调色预设同样有获取渠道与授权风险。

### 免版权 BGM 与音效

被问得最多的就是「配乐去哪找才不会侵权」。挑之前先答三个问题——这三条决定你能不能用，比「站里有多少首歌」重要得多：

| 你要确认 | 为什么重要 | 常见误解 |
| --- | --- | --- |
| 能否商用 | 很多曲库区分「个人/非商业」与「商用」授权 | 以为「免版权」就等于能商用 |
| 是否要署名 | 部分授权要求在使用处标注作者与来源 | 以为免费就一定不用署名 |
| 平台二次分发是否覆盖 | 内容 ID 可能在你上传后声称版权 | 以为下载时没问题，上传后也一定没问题 |

- **「免版权」不等于「没授权条款」**：它多半是「免版税（royalty-free）」——付一次或免费获得使用权，但使用范围仍受条款约束。把授权页截图留存，比事后扯皮有用。
- **平台曲库优先**：主流视频平台自带的音频库通常与本平台的版权检测兼容，比通用曲库少一层风险。
- **音效与音乐分开看**：音效（SFX）与音乐（BGM）的授权条款往往不同，别混着用同一个判断。
- 具体用哪首、怎么铺声音，见 [影视制作 · 声音设计](/contents/摄像/影视制作/声音设计.md)。

### 图库与字体

- **字体是侵权高发区**：商用字体大多需要单独授权，「系统自带」不代表可以商用交付。下载前先确认授权范围。
- **图库看「能不能改」与「能不能卖」**：授权条款里「可否二次创作」「可否用于转售商品」常常分列。
- 调色与视觉风格参考见 [方法论 · 色彩理论](/contents/自媒体运营/方法论/色彩理论.md)。

### 插件 · 预设 · LUT

- **只从作者官方或可信市场买**：第三方转手的预设包常夹带过期版本或二手授权。
- **先看版本兼容**：插件与宿主软件的版本对应关系，是「买了用不了」最常见的原因。
- **预设只是起点**：套完 LUT 仍要按素材调整，脱离原理照搬预设，换一批素材就会失效。

> 原则：素材的坑几乎都出在授权上，而不是下载上——花两分钟读条款，比事后下架划算。
