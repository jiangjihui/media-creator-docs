## 怎么用这一层

- **纯新手**：先走 [新手路线](新手路线.md)，照着顺序把摄影或摄像的入门链走通，再回各板块读对应正文。
- **遇到具体难题**：直接用 [常用工具链接](常用工具链接.md) 跳到对应工具/素材站，或去 [教程社区](教程社区.md) 找专题教程。
- **别孤立看**：路线、社区、工具三篇是「导航」，真正的知识在摄影 / 摄像 / 设备 / 软件的正文里——这里是入口，不是终点。
