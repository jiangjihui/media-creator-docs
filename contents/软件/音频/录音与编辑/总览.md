# 录音与编辑软件 · 总览

> 音频的"剪辑调色"对应物：录音、降噪、混音、播客制作。按"角色"拆成两块：**DAW 选型**（Audition / Reaper / Logic 等）与**降噪与修复**（iZotope RX 类），并给出一条**播客工作流**。与视频衔接：音频可交付 [DaVinci Fairlight](/contents/软件/视频/剪辑与调色/DAVINCI.md) 或 PR + Audition。信息核对时点：**2026-08**。

## DAW 选型

| 维度 | Audition | Reaper | Logic Pro（Mac） | GarageBand（Mac 免费） | Pro Tools |
| --- | --- | --- | --- | --- | --- |
| 定位 | 播客 / 视频伴音 | 便宜全能 | Mac 生态全能 | 入门免费 | 录音棚标准 |
| 授权 | 订阅 | 买断（低价） | 买断（Mac） | 免费 | 订阅 / 买断 |
| 多轨 / 修复 | 强 | 强 | 强 | 中 | 强 |
| 学习曲线 | 中 | 中（可深度定制） | 中 | 低 | 陡 |

- **Audition**：与 PR / 视频工作流贴合，降噪 / 频谱修复开箱即用，播客友好。
- **Reaper**：授权极便宜、可深度定制、轻量，进阶玩家最爱。
- **Logic Pro**：Mac 独占、买断、自带海量素材与母带工具。
- **GarageBand**：Mac 免费入门，够用再升级 Logic。
- **Pro Tools**：录音棚 / 专业交付标准，但贵且陡。

> 选谁：视频伴音 / 播客 → Audition；要便宜可玩 → Reaper；Mac 全能 → Logic Pro；免费入门 → GarageBand。

## 降噪与修复

- **iZotope RX**（现归 Native Instruments）：行业标杆的"音频 Photoshop"——去环境噪、去齿音、去混响、去咔嗒、频谱修复。按需模块买，或用 Audition 内嵌的类似功能起步。
- **Acon Digital / 各 DAW 自带**：轻量降噪够日常。
- 原则：先做"源头降噪"（安静环境、好麦、近讲），后期修复只是兜底。

## 播客工作流（一条可抄的线）

1. 录制：近讲 + 防喷 + 安静房，单轨 / 双轨分轨录。
2. 剪辑：去口误、去静默、对齐电平。
3. 修复：降噪 + 去齿音 + 压缩。
4. 响度对齐：对准 **-16 LUFS（播客）/ -14 LUFS（YouTube）** 标准，避免忽大忽小。
5. 导出：WAV 母带 + MP3 分发。
