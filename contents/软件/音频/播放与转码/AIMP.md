# AIMP

> Windows 下的轻量高保真音频播放器，免费、无广告，音质口碑好、界面漂亮，还内建转码 / 抓轨 / 录音。客观为主，个人长期使用观察补充。信息核对时点：**2026-08**（以 aimp.ru 当前 v5.40 稳定线为描述基准，最新版见官网）。

## 概览

| 能力 | 说明 |
| --- | --- |
| 平台 | Windows（Vista+，含 x86 / x64 / ARM）；另有 Android 版；无原生 macOS / Linux（Linux 走 Wine） |
| 授权 | 免费 freeware，无广告、无内购、无订阅 |
| 格式（含无损） | 极广：MP3 / AAC / AC3 / APE / DTS / FLAC / OGG / OPUS / TTA / WV / WAV / WMA / M4A / MKA / AIFF / DSF·DFF（DSD）/ CUE 整轨 / 多种 tracker 模块 |
| 输出 | DirectSound / ASIO / WASAPI / **WASAPI 独占**；32-bit 音频处理 |
| 音质工具 | 18 段均衡器 + 内置音效（混响 / 镶边 / 合唱 / 变调 / 变速 / 回声 /  enhancer / 人声消除等）+ 音量归一（Peak / ReplayGain） |
| 曲库 | Music Library 音乐库、智能播放列表、多播放列表、评分 / 收听统计、CUE 书签 |
| 内建工具 | 音频转换器、录音机、CD 抓轨 |
| 联网 | 网络电台（可录流）、Last.fm / Libre.fm / ListenBrainz scrobbling、云盘（OneDrive / Drive / Dropbox / WebDAV）、播客 |
| 界面 | 可换肤（含 4K / HiDPI 皮肤）、本地 / 全局热键、多语言 |

一句话：它不追求"极客级可定制"（那是 Foobar2000）也不追求"曲库管理最强"（那是 MusicBee），追求"装好就漂亮、音质稳、还能顺手转码抓轨"的一站式听歌体验。

## 获取与安装

### 官方下载

- **官网**：[aimp.ru](https://aimp.ru) 直接下载，无需注册账号；Windows 提供 **32 位 / 64 位 / ARM（Windows 11 on ARM 专用）** 安装包，以及"无安装包版"（解压即用，但可能不继承旧版设置）。
- **版本选择**：日常用 **v5.40 稳定线**；官网同时提供 v6 测试版（Beta，可能含 bug）与 nightly 构建，普通用户不要碰。ARM 机型（如骁龙本）选 ARM 构建。
- **安装注意**：安装向导里留意是否勾选附加项；装完默认关联常见音频格式，可在 `选项 → 关联` 调整。下载只走官方，不要从网盘 / 破解站拿——免费软件没必要，且易被塞料。

### 系统要求与音频架构

- **平台**：Windows Vista 及以上（含 Win11）；不原生支持 macOS / Linux。想在 Linux 用只能 Wine 跑 Windows 版，体验打折。
- **音频输出**：支持 **WASAPI 独占模式**与 **ASIO**，是拿"最好音质"的两个关键开关——独占模式绕过系统混音器、直出到声卡，避免被系统音效/SRC 污染；ASIO 适合接外置声卡 / 专业设备。
- **处理精度**：全程 32-bit 音频处理，EQ 与音效在浮点域运算，避免多级处理累积失真。
- **资源占用**：轻量，常驻内存小，老机器也跑得动；比 Foobar2000 略重但远轻于任何 DAW。

### 授权与成本

- **完全免费（freeware）**，无广告、无内购、无订阅，作者靠捐赠维持。
- 全功能无阉割，不像某些"免费版限制格式"的播放器。
- 成本结论：零。唯一"成本"是你可能想顺手捐一点给开发者。

## 核心能力

### 定位与竞品坐标

- 对 **Foobar2000**：AIMP 开箱即漂亮、功能集成度高（转码/抓轨/录音全有）；Foobar2000 赢在极简、组件无限、可深度定制，但默认朴素、上手门槛高。
- 对 **MusicBee**：AIMP 界面更现代、轻；MusicBee 赢在曲库 / 标签 / 歌词 / 同步管理最全。
- 对 **VLC（视频播放器）**：AIMP 只做音频、音质与听歌体验更专；VLC 是万能视频 / 验片工具、不播也别用它听歌。作者明确说过 AIMP **不打算支持视频播放**，要播视频请交给 VLC。

**独特卖点**：**免费 + 漂亮 + 音质稳 + 内建转码抓轨** 四位一体，是"想认真听歌又不想折腾"的省心默认值。

### 功能详述

- **多格式播放**：覆盖主流有损 / 无损（FLAC / APE / WAV / WV / TTA / AIFF），连 **DSD（DSF / DFF）** 与 **CUE 整轨**都支持；tracker 模块（MOD / IT / XM / S3M）也能放，复古游戏音乐党友好。
- **高保真输出**：WASAPI 独占 / ASIO + 32-bit 处理，配合 **18 段均衡器**与一票内置音效（混响、镶边、合唱、变调、变速、回声、低频增强、人声消除等），还能做音量归一（Peak / ReplayGain）与淡入淡出、交叉淡变，连曲过渡顺滑。
- **音乐库与列表**：Music Library 把曲库组织成可筛选 / 分组的数据库；智能播放列表按条件自动生成；支持多播放列表并行（一个在播、一个在排）；评分、收听统计、CUE 书签一应俱全。
- **内建工具三件套**：音频转换器（批量格式互转、多线程）、录音机（录线路 / 麦克风）、CD 抓轨（转成无损 / 压缩），不必另开软件。
- **联网能力**：听网络电台并能**把流录制**成 APE / FLAC / OGG / WAV / WV / WMA / MP3；内建 Last.fm / Libre.fm / ListenBrainz scrobbler 同步收听记录；可挂 OneDrive / Google Drive / Dropbox / WebDAV 云盘与播客源。
- **界面与自动化**：皮肤可换（自带 Bliss / Pandemic 等、支持 4K / HiDPI），本地与全局热键自由配置，多语言界面，多用户模式。

### 工作流定位

AIMP 适合做创作者的**本地高保真回放 + 轻量音频预处理**工具：

```
无损母带 / 曲库 → AIMP 回放（WASAPI 独占听细节）→ 内建转换器批量转分发格式
CD → AIMP 抓轨 → 无损归档；网络电台 → AIMP 录流 → 素材库
```

- 与视频剪辑互补：成片的伴音、采样素材，用 AIMP 做"安静环境下的音质验收"很合适。
- 转码场景：把 WAV / FLAC 母带批量压成 MP3 / AAC 分发，不必开 FFmpeg 命令行。
- 抓轨场景：实体 CD 转数字归档，一条龙完成。

### 常用技巧

- **开 WASAPI 独占拿最好音质**：`选项 → 音频输出 → 输出设备` 选 `WASAPI` 并勾「独占模式」；听歌时其他程序的声音会被让位（或按需在独占设置里允许混音）。接外置声卡 / 解码器时优先 ASIO。
- **批量转码**：`Ctrl+U` 打开音频转换器，拖入文件 → 选输出格式（FLAC / MP3 / AAC 等）与参数 → 开始；多线程编码速度快，适合母带压分发版。
- **CD 抓轨**：插入 CD → `工具 → 抓轨` 选音轨与输出格式（建议 FLAC 归档）→ 编码。
- **录网络电台**：播放电台时 `工具 → 录音机` 或右键电台选录制，可存为 APE / FLAC / WAV / MP3 等。
- **CUE 整轨**：直接把 `.cue` 加进播放列表，AIMP 会按音轨拆分显示，像播分轨一样跳曲。
- **EQ / 音效预设**：`Alt+G` 开均衡器后可在预设里挑现成曲线，或手调 18 段；`Alt+E` 开关混响 /  enhancer 等音效——注意音效会改变音色，鉴音时建议关掉。
- **云盘挂载**：`播放列表 → 添加 → 云存储` 登 OneDrive / Drive / Dropbox / WebDAV，直接播网盘里的音乐。

### 使用体验速记

> 以下为长期使用观察（待你按真实体验校订）：装好即漂亮、基本不用调就顺手；WASAPI 独占下听无损细节明显比系统默认混音干净；内建转码 / 抓轨 / 录音让"听歌 + 整理素材"闭环在一款软件里；皮肤与热键自定义够用。短板是曲库管理的精细度不如 MusicBee、可玩性不如 Foobar2000；DSD 直通需要声卡与设置配合，踩坑时先查输出模式。

## 适用人群与误区

### 优缺点

**优点**

- 免费、无广告、全功能无阉割。
- 音质稳：WASAPI 独占 / ASIO + 32-bit 处理，听无损体验好。
- 界面漂亮、轻量、低占用，开箱即用。
- 内建转码 / 抓轨 / 录音，听歌与轻量预处理一站搞定。
- 格式极广，含 DSD 与 CUE 整轨。

**缺点**

- 只支持 Windows（及 Android），无原生 macOS / Linux。
- 不播视频（作者明确不做）。
- 曲库管理深度不如 MusicBee，可定制性不如 Foobar2000。
- 非专业剪辑 / DJ 软件，别指望做多轨混音。

### 适用 / 不适用人群

- **适用**：想在 Windows 上认真听歌、追求音质与漂亮界面的人；无损 / DSD 党；想要"转码 + 抓轨 + 录音"顺手集成的人；网络电台 / scrobbling 爱好者。
- **不适用**：需要 macOS / Linux 原生播放器 → 选对应平台软件（如 macOS 的 Apple Music / Vox）；要播视频 → VLC / mpv；要极客级可定制 → Foobar2000；要最强曲库管理 → MusicBee；要做音频剪辑 / 播客 → 录音与编辑类 DAW。

### 常见误区

- "AIMP 能播视频"——不能，作者明确不做，视频请交给 VLC。
- "AIMP 跨平台"——只 Windows + Android，macOS / Linux 无原生版（Linux 只能 Wine）。
- "开了 EQ / 音效音质一定更好"——音效是染色，鉴音或追求原汁原味时应关闭，独占输出本身才是关键。
- "音质一定比 Foobar2000 好"——二者底层都能做到位，差异更多在默认体验与可玩性，别神话。

## 自查清单

- 没声音 / 声音怪 → 检查输出设备是否选对、WASAPI 独占是否被别的程序占用。
- DSD 不识别 / 不出声 → 确认输出模式支持 DSD 直通、声卡驱动到位。
- 想拿最好音质 → 开 WASAPI 独占（或 ASIO），并关闭 EQ / 音效染色。
- 要压分发版 → 用 `Ctrl+U` 转换器批量转 MP3 / AAC，母带（WAV / FLAC）别动。
- 实体 CD 数字化 → 用抓轨功能转 FLAC 归档。
