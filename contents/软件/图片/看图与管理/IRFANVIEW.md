# IrfanView

> Windows 下的老牌"看图 + 轻量批处理"瑞士军刀：体积约 8 MB、秒开大图、批量转格式 / 重命名 / 加水印一把抓，还内置截图与 OCR。客观为主，个人长期使用观察补充。信息核对时点：**2026-08**（官方最新 4.75，4.7x 系列持续维护；RAW 与更多格式需另装 Plugins 插件包）。

## 概览

| 能力 | 说明 |
| --- | --- |
| 看图速度 | 极快，秒开大图、内存占用低 |
| 格式支持 | 原生广 + 插件包覆盖 RAW / PSD / PDF / 字体等 |
| 批量处理 | 批量转格式 / 重命名 / 改尺寸 / 加水印 |
| 截图 | 全屏 / 窗口 / 区域捕获 |
| 基本编辑 | 裁剪、旋转、缩放、色彩自动校正、红眼 |
| 幻灯片 / 壁纸 | 放映、设为壁纸、屏保 |
| OCR | 插件（Tesseract）识别文字 / 二维码 / 条码 |
| 平台 | Windows 专属（含 ARM64） |

一句话：Windows 下"最快看图 + 批处理 + 截图"的默认神器，免费个人用、体积小、启动快。

## 获取与安装

### 官方下载与版本

- **官网**：[irfanview.com](https://www.irfanview.com/) 下载主程序（约 8 MB）+ **Plugins 插件包**（约 20 MB，RAW / 更多格式 / 多媒体必需）。32 / 64 位与 ARM64 各自选择；建议主程序与插件包版本保持一致。
- **版本**：**4.7x 系列**（截至 2026-08 官方最新 **4.75**），长期持续维护，更新以小幅增强与插件修复为主。
- **安装注意**：装完默认关联常见图片格式，可在 `选项 → 属性/设置 → 文件关联` 调整；插件包务必单独安装，否则 RAW / PSD / PDF 等打不开。

### 系统要求与硬件加速

- **平台**：Windows XP–11 全支持（含 32/64 位与 ARM64），是它区别于跨平台看图器的根本边界。
- **资源占用**：极轻量，老机也能秒开；RAW 预览由 CamRAW 插件负责，装插件后直接浏览相机 RAW（仅浏览，非显影）。
- **格式广度**：原生覆盖常见位图；装 Plugins 后扩展 Camera RAW、PSD、PDF、CAD、矢量 / 字体等数十种格式。

### 授权与成本

- **个人非商业免费**；**商用需购买授权**（这是它和"完全自由软件"的本质区别，企业环境别误用）。
- 无广告、无订阅、无水印；插件包同样免费个人用。
- 成本结论：个人零成本；商用按官方许可付费。

## 核心能力

### 定位与竞品坐标

- 对 **XnView MP**：XnView 跨平台、格式更广、带基础 DAM 与批量；IrfanView 胜在 Windows 下最快 + 体积最小 + 多年成熟。
- 对 **Honeyview / FastStone**：更轻量纯看图；IrfanView 额外有强批处理与截图。
- 对 **nomacs**（开源跨平台）：nomacs 跨平台、UI 更现代；IrfanView 在 Windows 速度与批处理上仍占优。

**独特卖点**：**8 MB 体积 + 秒开 + 批处理一把抓**（转格式 / 重命名 / 改尺寸 / 水印）+ 命令行可控（`i_view64.exe` 参数）+ Total Commander 深度集成。它是"给任何 Windows 用户推荐都不会错"的看图默认项。

### 功能详述

- **看图**：缩略图浏览、全屏连续播放、内存占用低，翻千张照片不卡。
- **批量处理**：批量转换 / 重命名（支持模板与计数器重命名、尺寸 / 格式 / 水印批量），处理上千张照片高效；3.0 后期版本支持多线程转换（老插件可能不支持）。
- **截图**：`选项 → 捕获`，可选全屏 / 窗口 / 区域、可定时，捕获后直接保存或进编辑器。
- **基本编辑**：裁剪、旋转 / 微调旋转、缩放、色彩自动校正（gamma / 对比度 / 饱和度）、红眼消除、添加边框——够用但不替代精修软件。
- **格式扩展**：装 Plugins 后支持 Camera RAW（CamRAW，仅浏览）、PSD、PDF、CAD、字体等。
- **OCR**：Tesseract 插件识别图片文字、二维码、条码。
- **多媒体**：插件可播部分视频 / 音频（非主业）。
- **命令行自动化**：`/slideshow`、`/effect`、`/convert` 等参数，适合批处理脚本与 Total Commander 联动。

### 工作流定位

IrfanView 在摄影工作流里做**初筛 / 快速浏览 / 批量转格式重命名 / 导出小样**，把重活交给显影与精修软件：

```
拍完导入 → IrfanView 初筛 / 比片 → 批量转格式 / 重命名 / 导出小样 → 进 Lightroom / C1 / GIMP 显影精修
```

- 与 RAW 显影软件衔接：IrfanView 只浏览 RAW，显影交给 Lightroom / C1 / darktable，精修交给 GIMP。
- 日常截图 / 批量水印：轻量场景一软搞定，不必开大型软件。

## 上手与使用

### 学习曲线

极浅，开箱即用；菜单扁平，常用功能一眼找到；批量对话框参数稍多，配好模板可反复用。对新手几乎零门槛。

### 常用快捷键

> 以下为默认键位（可在 `选项 → 属性/设置 → 快捷键` 重映射）；不同版本可能微调。

| 场景 | 快捷键 | 作用 |
| --- | --- | --- |
| 导航 | `←` / `→` | 上一张 / 下一张 |
| 视图 | `+` / `−` | 放大 / 缩小 |
| 视图 | 双击画面 | 全屏切换 |
| 旋转 | `Ctrl+R` / `Ctrl+Shift+R` | 顺时针 / 逆时针旋转 90° |
| 编辑 | `Ctrl+Y` | 裁剪选中区域 |
| 编辑 | `Ctrl+S` / `Ctrl+Shift+S` | 保存 / 另存为 |
| 编辑 | `Ctrl+C` / `Ctrl+V` / `Ctrl+A` | 复制 / 粘贴 / 全选 |
| 桌面 | `b` | 设为桌面壁纸 |
| 输出 | `Ctrl+P` | 打印 |
| 批处理 | 文件 → 批量转换/重命名 | 批量转格式 / 重命名（无默认快捷键，可在选项中自定义） |
| 截图 | 选项 → 捕获 | 截图（可在选项中设快捷键） |

### 常用技巧

- **批量转格式 + 重命名**：`文件 → 批量转换/重命名`，选输出格式、尺寸、重命名模式（计数器 / 模板），可加水印 / 插件特效；上千张照片高效处理。
- **微调旋转裁掉歪斜**：先用鼠标框选区域，`Ctrl+Y` 裁剪；倾斜用"图像 → 微调旋转"救正。
- **RAW 浏览**：装 Plugins 后 CamRAW 插件即可直接在 IrfanView 看相机 RAW（仅浏览、非显影）。
- **截图**：`选项 → 捕获` 选范围与延时，捕获后直接保存或进编辑器，替代系统截图工具。
- **一键壁纸**：按 `b` 把当前图设为桌面壁纸。
- **命令行自动化**：`i_view64.exe /file=... /convert=...` 或 `/slideshow=list.txt /effect=(...)` 做批量 / 放映，可与 Total Commander 脚本联动。
- **色彩自动校正**：`图像 → 增强`（自动色彩 / 亮度 / 对比度）快速救暗图。

### 使用体验速记

> 以下为长期使用观察（待你按真实体验校订）：装一次几乎天天用；开图速度仍是 Windows 下第一梯队；批处理对话框参数多但配好模板可反复用；RAW 依赖插件、且只是浏览非显影；UI 朴素、二十年风格未大改，但"能用且快"就是它的价值。

## 适用人群与误区

### 优缺点

**优点**

- 个人免费、8 MB 极轻、秒开、启动快。
- 批量强（转格式 / 重命名 / 改尺寸 / 水印），截图内置。
- 格式靠插件极广，命令行可控、可自动化。
- 与 Total Commander 等文件管理器深度集成。

**缺点**

- Windows 专属，无 macOS / Linux 版。
- 非商业免费、**商用需授权**。
- 无 RAW 显影 / 图层 / 蒙版（不是修图软件）。
- UI 老旧，DAM / 检索弱（不如 digiKam / LR）。

### 适用 / 不适用人群

- **适用**：Windows 用户要最快看图 + 批处理 + 截图；摄影初筛 / 导出小样；日常图片快速处理。
- **不适用**：要跨平台 → XnView MP；要 RAW 显影 / 精修 → Lightroom / C1 / GIMP；要资产管理 / 检索 → digiKam / LR；macOS / Linux 用户 → nomacs / XnView MP。

### 常见误区

- "IrfanView 能修 RAW"——它只能**浏览** RAW（装插件），不能显影 / 精修。
- "免费 = 随便商用"——个人非商业免费，商用需购买授权。
- "IrfanView 是图片管理器"——它偏看图 + 批处理，不是完整 DAM（检索 / 星标弱）。
- "看不了 RAW 是软件不行"——多半是没装 Plugins 插件包，装 CamRAW 即可。

## 自查与延伸

### 自查清单

- 看 RAW 黑屏 / 不支持 → 装 Plugins 的 CamRAW 插件。
- 要批量转格式 → 用批量转换对话框（配好模板反复用）。
- 要跨平台 → XnView MP / nomacs。
- 要显影 / 精修 → 交给 Lightroom / C1 / GIMP。
- 商用 → 购买官方授权。
