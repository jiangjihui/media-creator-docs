# GIMP

> 开源免费的"Photoshop 替代"：图层、蒙版、选区、色彩调整、修复与合成一应俱全。GIMP 3.0（2025-03）补齐了**非破坏性滤镜**与 GTK3 现代化界面，大幅缩小与 Photoshop 的体验差距。客观为主，个人长期使用观察补充。信息核对时点：**2026-08**（主线 3.0.x，最新维护版 3.0.6，2025-10）。

## 概览

| 能力 | 说明 |
| --- | --- |
| 图层 / 蒙版 / 通道 | 全功能，像素级精修与合成的基础 |
| 非破坏性滤镜（3.0 新） | 常用滤镜可叠加为"可关 / 可排序 / 可重编辑"的图层效果栈 |
| 选区与路径 | 矩形 / 椭圆 / 自由套索、快速蒙版、贝塞尔路径转选区 |
| 色彩调整 | 曲线、色阶、色相/饱和度、白平衡、通道混合器 |
| 修复工具 | 修复笔刷、克隆、透视克隆、内容感知修复（Heal） |
| 文本与矢量 | 3.0 起文本样式（描边 / 阴影 / 斜角）可实时编辑 |
| 文件格式 | 原生 XCF；PSD 导出改善；PNG / JPEG / WebP / HEIF / TIFF / DDS 等 |
| 插件 / 脚本 | G'MIC 滤镜库、Python 3 插件、Scheme |

一句话：零成本、本地重、跨三平台的精修主力；3.0 后"调了半天想反悔"不再痛苦。

## 获取与安装

### 官方下载与版本

- **官网**：[gimp.org/downloads](https://www.gimp.org/downloads/) 直接下载，Windows / macOS / Linux 原生安装包齐全，无需注册账号。Linux 另提供 Flatpak / Snap / 官方 AppImage（官方 AppImage 自 3.0 起提供）。
- **版本**：主线 **3.0.x**（3.0 于 2025-03 发布，是 2.10 之后七年的首个大版本；最新维护版 3.0.6 于 2025-10）。旧 2.10 仍可用，但新项目建议直接用 3.x。XCF 工程文件 2.10 与 3.0 互相兼容。
- **安装体量**：约百 MB 级（含 GEGL/babl 引擎与帮助文档），远小于 PS；建议装到非系统盘。

### 系统要求与硬件加速

- **平台**：Windows / macOS / Linux 全支持；GTK3 后高分屏（HiDPI）缩放改善、Wayland 原生支持。
- **内存 / CPU**：大图与多图层、滤镜吃内存与 CPU；建议 8 GB+ 内存、SSD。没有独立 GPU 也能跑，但大量滤镜预览会更慢。
- **色彩管理**：3.0 进一步改善，配合校色显示器做准确调色更可靠。

### 授权与成本

- **完全免费、开源（GPL）**，无订阅、无广告、无内购、无导出水印。
- 全平台一致，团队里谁装都能用。
- 成本结论：零。唯一"成本"是自愿捐赠支持开发。

## 核心能力

### 定位与竞品坐标

- 对 **Photoshop**：PS 是行业标杆，动作/插件生态、文字与矢量、CMYK/专色更强，但订阅制；GIMP 零成本、本地重、跨平台，3.0 后差距明显缩小。
- 对 **Affinity Photo**：Affinity 一次买断、界面更精致、带 CMYK；GIMP 完全免费，适合不愿花一分钱的人。
- 对 **Photopea**：Photopea 是网页工具，应急开 PSD / 做简单合成方便；GIMP 是本地重应用，隐私与性能更好。

**独特卖点**：**非破坏性滤镜**（图层上的 fx 效果栈，可关 / 排序 / 重编辑）+ 完整图层体系 + 开源可扩展（G'MIC）。它是"不想订阅、又想本地重精修"的默认答案。

### 功能详述

- **非破坏性滤镜**：在图层上点 "fx" 图标添加滤镜效果，效果栈里可临时关闭、拖拽排序、点击重新编辑参数——不再靠反复 `Ctrl+Z` 退回。这是 3.0 最重要的升级。
- **选区体系**：矩形 / 椭圆 / 自由套索 / 模糊选择（魔棒）/ 按颜色选 / 剪刀 / 前景选择；配合**快速蒙版（Shift+Q）**做复杂选区，路径可转选区。
- **图层**：混合模式、图层组、3.0 支持多选图层整体移动 / 变换；画笔工具可自动扩展图层尺寸。
- **蒙版**：图层蒙版、通道，做无损局部调整的核心手段。
- **色彩调整**：曲线、色阶、通道混合器、白平衡、色相/饱和度，配合色彩管理使用。
- **修复**：修复笔刷、克隆、透视克隆、内容感知修复（Heal），应对污点 / 瑕疵 / 去物。
- **文本与矢量**：3.0 文本可加描边 / 阴影 / 斜角且仍能编辑内容、字体、尺寸。
- **文件交换**：PSD 导出改善、BC7 DDS、HEIF 与 JPEG-XL 元数据加载，跨软件协作更顺。

### 工作流定位

GIMP 适合做摄影工作流的**精修 / 合成**一环，而非 RAW 显影：

```
RAW 显影（Lightroom / Capture One / darktable）→ 导出 16bit TIFF → GIMP 精修 / 合成 → 输出
```

- 与显影软件衔接：RAW 在 Lightroom / C1 / darktable 里显影，导出 16 bit TIFF 再进 GIMP 做像素级处理。
- 应急开 PSD：临时查看 / 修改他人 PSD（注意图层样式非 100% 还原）。
- 开源党的主力精修台：零成本且可脚本化（Python 3 插件）。

## 上手与使用

### 学习曲线

工具箱 + 停靠面板（docks）的信息密度对新手有门槛；支持**多窗口 / 单窗口**模式切换；3.0 改善主题与 HiDPI，界面不再显旧。建议先学四条主线：**图层 → 蒙版 → 选区 → 曲线**，足以覆盖日常精修。

### 常用技巧

- **非破坏性编辑**：需要反复调的效果（降噪、锐化、色彩）尽量走图层 fx 效果栈，而不是直接"提交"到像素——随时可改可关。
- **蒙版做局部调整**：复制图层 → 添加图层蒙版 → 用黑色笔刷擦出需隐藏区域，无损地处理局部。
- **快速蒙版（Shift+Q）**：画一笔软选区后转成标准选区，做毛发 / 边缘类抠图很顺手。
- **曲线调色**：`颜色 → 曲线` 配合色彩管理做主调与风格；先整体后局部、先还原后风格。
- **批量处理**：GIMP 本体批处理弱，建议用 **BIMP** 插件或脚本；上千张转格式 / 加水印交给 IrfanView / darktable 更合适。
- **RAW 衔接**：不在 GIMP 里显影 RAW，显影交给 Lightroom / C1 / darktable，导出 16 bit TIFF 再进 GIMP。
- **G'MIC 插件**：一键滤镜库（降噪、艺术效果、修复、细节增强），是 GIMP 生态的"外挂军火库"。

### 使用体验速记

> 以下为长期使用观察（待你按真实体验校订）：GIMP 3.0 后体验明显现代化，非破坏性滤镜让"调了半天想反悔"不再痛苦；**CMYK / 专色仍是短板**，印刷前处理需转 PS 或专用流程；文字与矢量仍弱于 PS；大图多图层吃内存，建议 16 GB 起步。配置文件（快捷键、插件）可随工程迁移，换机成本不高。

## 适用人群与误区

### 优缺点

**优点**

- 完全免费开源、跨三平台、无订阅焦虑。
- 图层 / 选区 / 蒙版齐全，覆盖绝大多数精修与合成场景。
- 3.0 非破坏性滤镜，可复用、可反悔的编辑体验。
- 可扩展：G'MIC 滤镜库、Python 3 脚本自动化。

**缺点**

- 无原生 CMYK / 专色，印刷印前弱。
- 文字 / 矢量 / 部分高级修图不如 Photoshop。
- UI 仍偏"专业工具箱"风格，上手有门槛。
- 批量处理不擅长，需插件补足。

### 适用 / 不适用人群

- **适用**：不愿订阅、预算敏感；开源党；RGB 为主的网络 / 社媒出图；需要本地重、可脚本化的精修。
- **不适用**：印刷 / CMYK 印前 → Photoshop 或 Affinity Photo；已在 Adobe 全家桶深度协作 → PS；要最顺手文字 / 矢量 → Affinity / PS；要最轻量应急 → Photopea。

### 常见误区

- "GIMP 不如 PS 所以不能用"——日常精修 / 合成 90% 场景够用，3.0 后差距大幅缩小。
- "GIMP 能显影 RAW"——它不擅长，RAW 显影交给 Lightroom / C1 / darktable。
- "免费 = 低质"——GIMP 是志愿者主导的成熟项目，与 PS 同量级功能覆盖。
- "必须学所有工具"——先掌握图层 / 蒙版 / 选区 / 曲线四条主线即可上手。

## 自查清单

- 要印刷 CMYK？→ 别用 GIMP 直接做印前，转 PS / 专用流程。
- 要批量转格式 / 加水印？→ 用 IrfanView / BIMP 插件。
- 要开 PSD？→ 3.0 导出改善但仍非 100% 还原图层样式，验收前先核对。
- 要非破坏编辑？→ 用图层 fx 效果栈，别直接提交滤镜。
