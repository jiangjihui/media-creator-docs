# 修图与 RAW 软件 · 总览

> 图片的"剪辑调色"对应物：RAW 显影、修饰、调色、合成。按"角色"拆成三块：**RAW 显影与库管理**（Lightroom 类）、**精修与合成**（Photoshop 类）、**移动 / 轻量修图**（Snapseed 类），帮你按场景选。原理（曝光 / 色彩）见 [摄影 · 器材](/contents/摄影/器材/相机机身.md)，本栏只讲工具选型。信息核对时点：**2026-08**。

## RAW 显影与库管理（Lightroom 类）

这类工具的目标是"批量处理 RAW + 管理整个照片库"，核心是**非破坏性编辑**（原图不动，参数存 sidecar / 库）。

| 维度 | Lightroom Classic | Capture One | darktable（开源） |
| --- | --- | --- | --- |
| 定位 | 库管理 + 显影一体 | 画质与联机拍摄强 | 免费、跨平台 |
| 授权 | 订阅（Adobe CC） | 买断 / 订阅 | 开源免费 |
| 关键词 / 筛选 | 极强 | 强 | 中 |
| 联机拍摄（tether） | 支持 | 行业标杆 | 支持 |
| 适用 | 摄影量大的爱好者 / 职业 | 商业 / 人像 / 风光 | 预算敏感 / 开源党 |

- **Lightroom（Classic vs 云版）**：Classic 是本地库 + 显影的完整方案；云版（Lightroom / "CC"）偏向多设备同步、轻库。职业 / 大量归档选 Classic。
- **Capture One**：色彩与联机拍摄口碑最佳，许多商业影棚标配；索尼 / 富士有定制色彩，但订阅 / 买断成本高于 LR。
- **darktable**：开源免费、模块链灵活，学习曲线陡但零成本；适合不愿订阅、愿意折腾的用户。

> 选谁：要"库 + 显影一体、生态成熟" → Lightroom Classic；要"极致画质 / 联机拍摄" → Capture One；要"免费且可控" → darktable。

## 精修与合成（Photoshop 类）

当显影不够（抠图、合成、图层、蒙版、频率分离、内容识别），需要像素级工具。

| 维度 | Photoshop | Affinity Photo | [GIMP](GIMP.md)（开源） | Photopea（网页） |
| --- | --- | --- | --- | --- |
| 定位 | 行业标准 | LR 的好搭档、买断 | 免费开源 | 浏览器里开 PSD |
| 授权 | 订阅 | 一次买断 | 免费 | 免费 / 增值 |
| 图层 / 蒙版 / 通道 | 全 | 全 | 全 | 大部分 |
| 非破坏性滤镜 | 有 | 有 | 3.0 起有（fx 效果栈） | 部分 |
| 学习资源 | 极多 | 多 | 多 | 中 |

- **Photoshop**：和 Lightroom 组成"显影 + 精修"黄金组合，但订阅制。
- **Affinity Photo**：买断、功能覆盖绝大多数精修场景，是 PS 高性价比替代。
- **GIMP / Photopea**：零成本；GIMP 本地重、3.0 起补齐非破坏性编辑，Photopea 网页轻量（应急开 PSD / 做简单合成）。详见 GIMP 深度档案。

## 移动 / 轻量修图

- **Snapseed**（Google，免费）：手机端曲线 / 局部 / 画笔齐全，随手调。
- **Lightroom Mobile**：与桌面库同步，手机也能做非破坏显影。
- 适合"出片即发朋友圈 / 社媒"的轻量流程，不做大幅合成。

## 对比维度小结

| 角色 | 首选 | 关键判断 |
| --- | --- | --- |
| 库管理 + RAW 显影 | Lightroom Classic | 生态成熟、批量强 |
| 商业 / 联机 / 画质优先 | Capture One | 色彩与 tether 标杆 |
| 免费非破坏显影 | darktable | 开源、模块灵活 |
| 像素级精修 / 合成 | Photoshop / Affinity Photo | 图层蒙版通道全 |
| 手机随手调 | Snapseed / LR Mobile | 轻量、可同步 |
