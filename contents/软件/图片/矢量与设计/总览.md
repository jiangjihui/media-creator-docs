# 矢量与设计软件 · 总览

> 矢量图形、排版、平面设计工具选型。按"角色"拆成三块：**矢量插画**（Illustrator 类）、**排版版式**（InDesign 类）、**轻量模板设计**（Canva / Figma 类）。与 [修图与 RAW](../修图与RAW/总览.md) 的边界：矢量做"图形 / 文字 / Logo"，修图做"照片像素"，二者常配合但不重叠。信息核对时点：**2026-08**。

## 矢量插画（Illustrator 类）

| 维度 | Illustrator | Affinity Designer | Inkscape（开源） | CorelDRAW |
| --- | --- | --- | --- | --- |
| 定位 | 行业标杆 | 买断替代 | 免费开源 | Win 老牌 |
| 授权 | 订阅 | 一次买断 | 免费 | 买断 / 订阅 |
| 钢笔 / 贝塞尔 | 顶级 | 顶级 | 强 | 强 |
| 位图 / 矢量混合 | 强 | 强（双引擎） | 中 | 强 |

- **Illustrator**：与 PS、字体、插件生态无缝，职业设计默认。
- **Affinity Designer**：买断、双引擎（矢量 + 像素），性价比高。
- **Inkscape**：免费、SVG 原生，适合预算敏感 / 开源党。
- **CorelDRAW**：Windows 传统强、印刷 / 刻字场景多。

> 选谁：要生态 / 职业兼容 → Illustrator；要买断高性价比 → Affinity Designer；要免费 → Inkscape。

## 排版版式（InDesign 类）

长文档、画册、杂志、多页 PDF 用排版工具，而非在 PS / AI 里硬排。

| 维度 | InDesign | Affinity Publisher | Scribus（开源） |
| --- | --- | --- | --- |
| 定位 | 专业排版标杆 | 买断替代 | 免费开源 |
| 授权 | 订阅 | 买断 | 免费 |
| 主页 / 样式 / 导出 | 极强 | 强 | 中 |

- **InDesign**：书籍 / 画册 / 杂志首选，与 LR / PS 联动。
- **Affinity Publisher**：买断、够用，小团队 / 个人友好。
- **Scribus**：免费，适合轻量印刷品。

## 轻量模板设计（Canva / Figma 类）

- **Canva**：模板化、零门槛、协作分享，社媒图 / 简单海报首选。
- **Figma**：网页 UI / 界面设计标杆，免费档够用，也做轻量图形；偏向界面 / 原型而非印刷。

> 这类工具"重模板、轻专业控制"，适合快速出图；要印刷级色彩 / 出血 / 字体控制仍回 AI / ID。

## 对比维度小结

| 角色 | 首选 | 关键判断 |
| --- | --- | --- |
| 矢量插画 / Logo | Illustrator / Affinity Designer | 钢笔与生态 |
| 免费矢量 | Inkscape | SVG 原生、零成本 |
| 专业排版 | InDesign / Affinity Publisher | 多页 / 样式 / 出血 |
| 免费排版 | Scribus | 轻印刷品 |
| 模板 / 社媒快出 | Canva | 零门槛协作 |
| UI / 界面设计 | Figma | 网页原型标杆 |
