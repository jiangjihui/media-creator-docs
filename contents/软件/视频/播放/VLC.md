# VLC

> 开源、跨平台、零配置的"万能播放器"，也是创作者回看素材与验片的安全默认值。客观为主，个人长期使用观察补充。信息核对时点：**2026-08**（桌面版 VLC 3.x 主线，360 支持自 3.0 起）。

## 概览

| 能力 | 说明 |
| --- | --- |
| 格式支持 | 极广，内嵌 FFmpeg，几乎"什么都能播" |
| 跨平台 | Windows / macOS / Linux |
| 字幕 | 内嵌 / 外挂 / 网络字幕完善 |
| 转码 | 内置转码（Convert） |
| 网络串流 | 支持 Open Network Stream |
| 360 全景 | 3.0+ 内置 VR 视频滤镜（桌面环视） |

一句话：它不追求"画质调优最深"或"界面最漂亮"，追求"丢给它任何文件都不报错"。

## 获取与安装

### 官方下载

- **官网**：[videolan.org/vlc](https://www.videolan.org/vlc/) 直接下载，无需注册账号，三平台安装包齐全；国内访问若慢，也可走系统包管理器：`winget install videolan.vlc`（Windows）、`brew install --cask vlc`（macOS）、各发行版自带源。
- **版本**：分 32/64 位与 ARM 版，按系统选；桌面端主线为 3.x，移动端为 VLC for Android/iOS（功能略简）。
- **安装注意**：安装向导里会附带"捐赠/推广"勾选项，按需取消；装完默认关联常见音视频格式，可在 `工具 → 偏好设置 → 文件关联` 调整。

### 系统要求与硬件加速

- **平台**：Windows / macOS / Linux 全支持。
- **硬件加速解码**：支持（需开启），可显著降低高码率回放占用；Windows 下部分格式默认走 CPU，卡顿时可手动开硬件解码（`工具 → 偏好设置 → 输入/编解码器 → 硬件加速解码` 选 DXVA2/自动）。
- **资源占用**：中等，比 mpv 重、比浏览器播放轻；老机器播 4K/8K 高码率仍需独显加速。
- **360 播放**：需要较强的 GPU 支持与更新的显卡驱动；高分辨率 360 在老硬件上会卡。

### 授权与成本

- **完全免费、开源（GPL）**，无广告、无内购、无订阅。
- 全平台一致，团队里谁装都能用。
- 成本结论：零。唯一"成本"是你可能想顺手捐一点给 VideoLAN 项目。

## 核心能力

### 定位与竞品坐标

- 对 **PotPlayer**：VLC 赢在跨平台与零配置、还能转码串流；PotPlayer 赢在 Windows 本地画质调优与字幕特效。
- 对 **mpv**：VLC 开箱即用、GUI 完整；mpv 更轻、更可脚本化、画质管线更可调，但上手门槛高。
- 对 **专用全景播放器**：VLC 的 360 是"桌面转着看"，不是头显级沉浸。

**独特卖点**：**没有它播不了的文件** + 跨三平台一致体验 + 免费开源无广告。它是"给任何人推荐都不会错"的默认项。

### 核心功能

- **万能解码**：内嵌 FFmpeg，H.264/H.265、MKV/MP4/MOV/WebM 等主流容器与编码基本通吃。
- **字幕**：外挂（srt/ass）、内嵌、甚至部分网络字幕源；ass 特效字幕渲染良好；同名同目录字幕自动加载。
- **转码与串流**：`媒体 → 转换/保存`、`媒体 → 打开网络串流`，临时转格式或拉流。
- **播放控制**：倍速、音轨切换、声画延时校正（对口型很有用）。
- **360 全景（3.0+）**：通过"VR 视频滤镜"把等距矩形画面映射回球面，鼠标拖拽环视（详见下节）。

### 360 全景播放（重点）

- **前提**：文件须为**等距矩形（equirectangular）**布局（360 相机/剪辑导出默认如此）。若文件是鱼眼、立方贴图等其他投影，VLC 即使开滤镜也显示不对，需先用外部工具转成等距矩形。
- **元数据**：带正确球面元数据时 VLC 可能自动识别；但 360 支持是以**滤镜**形式实现、**默认不启用**——很多"看起来是扁的"其实只是滤镜没开，不是文件坏了。
- **手动开启**：`工具 → 偏好设置 → 显示设置 = 全部 → 视频`，找到 Projectors/VR 相关项启用；或更新到较新版本后播放 360 文件时按提示进球面模式。
- **操作**：鼠标在画面内拖拽即可上下左右环视；按键可缩放（PageUp/Down）、倾斜/旋转视角（方向键）、重置视角（R）。
- **局限**：VLC 只做桌面"旋转看"，**不模拟深度、无头显级头部追踪**；空间音频同步、自动地平线校正等高级特性不在其范围。要求沉浸式 → 用专用全景播放器。

> 实用建议：360 成片导出后，**保留原始带元数据的文件**；二次转码容易把球面元数据冲掉，导致 VLC 当成扁片播。

### 工作流定位

VLC 适合做创作者的**通用回看/验片工具**：

```
素材/成片 → VLC 回看（核对构图、色彩、字幕、声音）→ 转码导出小样 → 发给客户/自己
```

- 与剪辑软件互补：剪辑软件导出的成片，用 VLC 做"第三方视角"验收（避免只在时间线里自我感觉良好）。
- 转码场景：临时把某格式转成协作方能开的格式，不必开专业转码软件。
- 360 成片预检：导出后先用 VLC 确认球面映射正常，再交付。

## 上手与使用

### 常用快捷键

> 以下为桌面版默认键位（Windows/Linux；macOS 大多把 Ctrl 换成 ⌘）；可在 `工具 → 偏好设置 → 热键` 重映射。

| 场景 | 快捷键 | 作用 |

| 播放 | `Space` | 播放 / 暂停 |

| 播放 | `M` | 静音 |
| 播放 | `Ctrl+↑` / `Ctrl+↓` | 音量 ±5% |
| 导航 | `←` / `→` | 快退 / 快进数秒 |
| 导航 | `Shift+←` / `Shift+→` | ±3 秒；`Ctrl+←/→` ±1 分钟；`Alt+←/→` ±10 秒 |
| 导航 | `N` / `P` | 下一 / 上一 曲目 |

### 常用技巧

- **临时转码**：`媒体 → 转换/保存`，加文件 → 选输出配置文件（如 MP4/H.264）→ 设目标路径 → 开始；可把大文件压成小样发给客户。
- **网络串流**：`媒体 → 打开网络串流` 粘贴 URL（如直播流、网盘直链），无需下载即可播。
- **声画不同步**：字幕对不上用 `G`/`H` 微调；音轨整体偏移在 `工具 → 轨道同步` 里调。
- **设为默认播放器**：`工具 → 偏好设置 → 文件关联` 勾选格式，双击即用 VLC 开。
- **投屏**：`播放 → 渲染器` 选 Chromecast 等，把画面推到电视。
- **A-B 循环 / 截图目录**：A-B 循环在播放控制里开；截图默认存 `图片` 文件夹，可在 `工具 → 偏好设置 → 视频` 改"视频快照目录"。

### 使用体验速记

> 以下为长期使用观察（待你按真实体验校订）：装一次全家受益，几乎从不需要为"格式打不开"发愁；回看成片做第三方验收很稳；360 偶尔要手动开滤镜这点容易让新手误以为文件坏了；高码率 4K/8K 在核显老机上会卡，开硬件解码后明显好转。

## 适用人群与误区

### 优缺点

**优点**

- 免费开源、全平台、无广告。
- 格式兼容性近乎"万能"，回看任何素材都不慌。
- 零配置开箱即用；还能转码与串流。
- 360 桌面环视内建（3.0+），偶尔看全景片够用。

**缺点**

- 画质调优与字幕特效不如 PotPlayer 深。
- 界面朴素、可定制性弱于 mpv。
- 360 是桌面级、非头显沉浸；老硬件播高分辨率 360 会卡。
- 资源占用比 mpv 重。

### 适用 / 不适用人群

- **适用**：需要"什么都能播"的默认播放器的人；跨平台团队；要快速转码/串流的人；偶尔回看 360 成片的人。
- **不适用**：追求 Windows 本地画质/字幕极致 → PotPlayer；想脚本化/最低占用/最高画质管线 → mpv；频繁交付头显 360 → 专用全景播放器。

### 常见误区

- "VLC 播不了某格式=文件坏了"——多是不能硬件解码或需开滤镜。
- "VLC 能当 VR 头显播放器"——它只是桌面环视。
- "VLC 画质差"——默认直出中性，刻意做画质调优确实不如 PotPlayer/mpv，但"能播"才是它的价值。

## 自查与延伸

### 自查清单

- 播放卡 → 开硬件加速解码。
- 360 是扁的 → 检查元数据 + 手动开 VR 滤镜。
- 要转小样给客户 → 用 Convert。
- 字幕对不上 → `G`/`H` 微调或 `轨道同步`。
