# 播放软件 · 总览

> 播放器是创作者"回看素材、核对成片、验收调色"的 daily driver，也是给客户/自己看片的基础工具。本文按"角色"拆成三块：**全能型**（VLC / PotPlayer）、**极致轻量型**（mpv）、**360 全景播放**（VLC 与 mpv 各怎么搞），帮你按场景选，而不是盲装一个"万能播放器"。

## 全能型：VLC / PotPlayer

这类播放器目标是"什么都能播、什么格式都不怕"，适合日常看片、验片、转码预览。

| 维度 | VLC | PotPlayer |
| --- | --- | --- |
| 授权 | 开源免费（跨平台） | 免费（Win 为主） |
| 平台 | Win / macOS / Linux | Windows |
| 格式支持 | 极广（内嵌 FFmpeg） | 极广，解码调优细腻 |
| 字幕 | 内嵌/外挂/网络字幕完善 | 字幕渲染与特效强 |
| 转码/流 | 内置转码、网络串流 | 支持，但偏本地播放 |
| 上手 | 开箱即用，设置少 | 设置项极多，可深度调 |

- **VLC**：跨平台、零配置、还能转码和拉流，是"给任何人推荐都不会错"的默认项。
- **PotPlayer**：Windows 下的本地播放王者，画面调优、字幕特效、快捷键定制更极致，但只在 Windows、且设置项对新手偏多。

> 选谁：要跨平台/转码/串流 → VLC；纯 Windows 且想榨干画质与字幕 → PotPlayer。

## 极致轻量型：mpv

mpv 是开源（GPL）播放器，**几乎无界面包袱、启动极快、纯 GPU 渲染管线**，靠文本配置（mpv.conf）和 lua 脚本/GLSL 着色器扩展。它不给你"媒体库""漂亮皮肤"，但给你**最高的可玩性与最低的资源占用**。

- **强项**：体积与内存占用极小；GPU 着色器链（deband、锐化、Anime4K 等）画质可调到极致；lua 脚本生态（自动加载、播放列表、字幕翻译等）；命令行/IPC 可嵌入工作流。
- **代价**：无内置媒体库、默认几乎无 GUI；上手靠改配置和脚本，新手门槛高。
- **适合**：喜欢折腾、追求画质与效率、愿意写配置的进阶玩家；以及需要把播放嵌进脚本/流水线的场景。

> mpv 与 VLC 不冲突：VLC 当"给所有人用的默认播放器"，mpv 当"自己的画质/脚本工作台"。

## 360 全景播放

360° 视频是等距矩形（equirectangular）铺平的球面画面，普通播放器会把它当"拉长的大饼"播。**要在桌面上环视，需要播放器把画面映射回球面并允许鼠标转动视角**——这不是"换个播放器自动就有"，而是依赖特定能力：

- **VLC（3.0+）**：内置"VR 视频滤镜"，打开带球面元数据的等距矩形文件时，可用鼠标拖拽环视。详见 [VLC](VLC.md) 档案的 360 小节。注意：VLC 不做头显级深度/头部追踪，是桌面"转着看"，不是沉浸式 VR。
- **mpv**：默认不内建 360 球面导航，但可通过社区 lua 脚本（如 `mpv360.lua`）实现等距矩形/鱼眼/立方贴图等多种投影的交互查看。详见 [mpv](MPV.md) 档案的 360 小节。
- **专业全景播放器**：Insta360 Player、GoPro Player、Whirligig 等，对头显、立体、自动校正向导更友好，适合频繁产 360 内容的创作者。

> 结论：偶尔看 360 成片 → VLC 够用；重度或想自定义投影/脚本 → mpv + 脚本；经常交付给客户头显看 → 专用全景播放器。

## 对比维度小结

| 角色 | 首选 | 关键判断 |
| --- | --- | --- |
| 日常全能播放 / 跨平台 | VLC | 零配置、格式广、能转码串流 |
| Windows 本地画质/字幕极致 | PotPlayer | 解码调优深、字幕特效强 |
| 轻量 / 画质可调 / 脚本化 | mpv | 资源占用低、着色器链强、靠配置 |
| 360 全景桌面环视 | VLC（或 mpv+脚本） | 需等距矩形 + 球面映射能力 |
| 头显/立体/客户交付 | 专用全景播放器 | 向导与头显支持更完整 |
