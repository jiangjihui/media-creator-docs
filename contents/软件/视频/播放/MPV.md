# mpv

> 开源（GPL）、跨平台、极简的"玩家级"播放器：几乎无界面包袱、启动极快、纯 GPU 渲染管线，靠文本配置与 lua 脚本/GLSL 着色器扩展。客观为主，个人长期使用观察补充。信息核对时点：**2026-08**（主线 mpv，配置与脚本生态持续活跃）。

## 概览

| 能力 | 说明 |
| --- | --- |
| 渲染 | 纯 GPU（vo=gpu，基于 libplacebo/Vulkan/OpenGL），画质管线可调 |
| 着色器链 | GLSL 着色器：deband、锐化、Anime4K、CAS 等 |
| 脚本 | lua 脚本生态：自动加载、播放列表、字幕翻译等 |
| 配置 | 纯文本 mpv.conf，可版本化管理 |
| 命令行/IPC | JSON IPC，可嵌入脚本与工作流 |
| 资源占用 | 极低，启动快 |

一句话：它不给你好看的皮肤和媒体库，但给你**最低的占用与最高的可玩性**。

## 获取与安装

### 官方下载与 Windows 便携版

- **官网**：[mpv.io](https://mpv.io/) → [安装页](https://mpv.io/installation/)。官方只提供源码与构建说明，桌面用户通常走渠道：
  - Windows：包管理器 `winget install mpv` / `scoop install mpv` / `choco install mpv`；或下载社区构建（如 shinchiro 版）的**便携 zip**，解压即得 `mpv.exe`，双击即播、无需安装。
  - macOS：`brew install mpv`，或图形前端 IINA（基于 mpv）。
  - Linux：各发行版源直接装（`apt/dnf/pacman install mpv`）。
- **版本选择**：稳定版即可；想追新特性可用每日构建。便携版建议解压到固定目录（如 `C:\Apps\mpv`），方便文件关联与更新。

### 配置目录与文件

mpv 没有"设置窗口"，一切靠**纯文本配置文件**，启动时读取：

| 文件 / 目录 | 作用 | 典型位置 |
| --- | --- | --- |
| `mpv.conf` | 主配置（解码、窗口、字幕、音量、缩放等） | Windows：`%APPDATA%\mpv\`；便携版可用 `mpv.exe` 同目录的 `portable_config\` |
| `input.conf` | 自定义键位 | 同上 |
| `scripts\` | lua/JS 扩展脚本 | 同上 |
| `script-opts\` | 脚本参数 | 同上 |
| `shaders\` | GLSL 着色器（缩放/动画超分等） | 同上 |

- 不存在就自己建；便携版在 `mpv.exe` 旁建 `portable_config` 文件夹，mpv 会优先用它与程序同走，换机复制即还原。
- 改完配置**重启 mpv** 生效；行首 `#` 为注释。

### 系统要求与硬件加速

- **平台**：Windows / macOS / Linux 全支持。
- **GPU 渲染**：默认 vo=gpu，充分利用 Vulkan/OpenGL；画质与性能取决于显卡驱动。
- **资源占用**：极低，内存与 CPU 占用明显低于 VLC/浏览器播放；老旧机器也能流畅播 1080p。
- **解码**：支持硬件解码（vaapi / d3d11va / videotoolbox 等），高码率 4K 依赖独显加速；配置 `hwdec=auto-safe` 即可安全启用。

### 授权与成本

- **完全免费、开源（GPL）**，无广告无内购。
- 跨平台（Windows / macOS / Linux）。
- 成本结论：零。代价是"上手成本"——它要你愿意读文档、改配置、装脚本。

## 核心能力

### 定位与竞品坐标

- 对 **VLC**：mpv 更轻、画质管线更可调、可脚本化；VLC 开箱即用、GUI 完整、跨平台一致。
- 对 **PotPlayer**：两者都重画质调优；mpv 跨平台且开源可脚本，PotPlayer 仅 Windows 且偏 GUI 设置。
- **独特卖点**：**"轻量哲学"**——最小资源占用 + 最大可控性。你要的不是"它帮你决定怎么播"，而是"我写配置决定怎么播"。

### 核心功能

- **GPU 渲染管线**：基于 libplacebo，色彩管理、插值（帧率同步）、缩放算法均可精细配置。
- **着色器链**：通过 `glsl-shaders` 挂 GLSL 文件，做 deband（去色带）、锐化、Anime4K（动画超分）、CAS 等，画质可推到极高水平。
- **lua 脚本生态**：自动加载目录下字幕/音轨、播放列表管理、字幕翻译、按键自定义等。
- **纯文本配置**：`mpv.conf` + `input.conf`，可纳入 git 版本管理，换机一键还原。
- **命令行/IPC**：JSON IPC 让外部程序控制播放，适合工作流集成。

### 着色器与脚本（画质/自动化）

- **着色器链示例**：mpv.conf 里 `glsl-shaders="~~/shaders/deband.glsl;~~/shaders/sharpen.glsl"`，或在命令行 `--glsl-shader=...`，逐文件叠加效果。
- **常用脚本**：autoload（自动加载同目录媒体/字幕）、playlistmanager（播放列表）、 quality-menu（串流选清晰度）等，放在 `scripts\` 即生效。
- **IPC**：`--input-ipc-server` 暴露 socket，批处理/预览流水线可远程控制播放进度与状态。

### 工作流定位

mpv 适合做**进阶玩家的画质/脚本工作台**，也适合嵌入自动化：

```
素材/成片 → mpv（GPU 着色器画质调优 / lua 脚本批量验片）→ 命令行/IPC 嵌入流水线
```

- 与 VLC 互补：VLC 当"给所有人用的默认播放器"，mpv 当"自己的画质与脚本工具"。
- 自动化：用 `--script`、`--glsl-shader`、`--input-ipc-server` 把播放嵌进批处理/预览流水线。

### 360 全景播放（脚本实现）

- mpv **默认不内建 360 球面导航**——等距矩形 360 文件在 mpv 里会作为"拉长的大饼"播放。
- 交互查看依赖**社区 lua 脚本**，主流方案如 `mpv360.lua`：支持等距矩形、双鱼眼、立方贴图等多种投影，鼠标拖拽 + 键盘六自由度环视，并可切换左右眼（立体格式）。
- 用法：把脚本放进 mpv 的 `scripts\` 目录，按脚本绑定的快捷键（如开/关 360 模式、拖拽环视）即可。
- 对比 VLC：VLC 是**内置滤镜、开箱即用**；mpv 是**装脚本、自由度更高**（投影种类、键位、输出模式都可改）。重度或想自定义投影 → mpv + 脚本更合适。

> 实用建议：偶尔看 360 → VLC 省事；想自定义投影/键位/脚本化 → mpv + mpv360.lua。

## 上手与使用

### 常用快捷键

> 以下为默认键位（Windows/Linux）；可在 `input.conf` 自定义。注意 `↑/↓` 在**默认配置里是大步 seek（约 60 秒）**，音量用 `9`/`0`。

| 场景 | 快捷键 | 作用 |
| --- | --- | --- |
| 播放 | `Space` / 鼠标左键 | 播放 / 暂停 |
| 退出 | `q`（或 `Q` 保存进度退出） | 退出 |
| 导航 | `←` / `→` | 快退 / 快进约 5 秒 |
| 导航 | `Ctrl+←` / `Ctrl+→` | ±10 秒；`↑/↓` ±60 秒；`PageUp/Down` ±10 分钟 |
| 音量 | `9` / `0` | 音量 − / +；`m` 静音 |
| 速度 | `[` / `]` | 减速 / 加速 10%；`{` / `}` 半速 / 倍速；`Backspace` 复位 |
| 画面 | `f` | 全屏 |
| 截图 | `s` / `S` / `Ctrl+s` | 截图（带字幕）/ 无字幕 / 窗口 |
| 字幕 | `v` | 切换字幕显隐 |
| 字幕 | `j` | 循环字幕轨；`z`/`Z` 字幕延时 ±0.1 秒 |
| 播放列表 | `p` / `Enter` / `N` | 上一首 / 下一首 |

### 常用配置与技巧

- **基础 mpv.conf**（新手可抄）：
  ```
  hwdec=auto-safe        # 安全硬件解码
  profile=gpu-hq         # 高质量 GPU 渲染
  save-position-on-quit=yes   # 记住看到哪
  volume=80
  volume-max=150
  sub-auto=fuzzy          # 同目录模糊自动加载字幕
  sub-font-size=42
  ```
- **画质调优**：`profile=gpu-hq` + 挂 deband/锐化着色器，老旧片源观感提升明显。
- **便携配置**：把 `portable_config` 放在 `mpv.exe` 同目录，U 盘随身、换机即用。
- **自动加载**：装 autoload 脚本，双击一个视频即把同目录系列文件排成播放列表。
- **360 脚本**：下载 `mpv360.lua` 放入 `scripts\`，按需配置键位即可环视全景。
- **版本管理**：把 `mpv.conf` / `input.conf` / `scripts\` 纳入 git，调好的"一套配置"永久备份。

### 使用体验速记

> 以下为长期使用观察（待你按真实体验校订）：配置文件定好后"一次调优、处处生效"，换机复制 mpv.conf 即还原；GPU 着色器把老片画质救活很爽；初期卡在"为什么没界面、怎么加载字幕"，熬过配置期后几乎回不去 VLC；360 装一次 mpv360.lua 后体验顺滑。

## 适用人群与误区

### 优缺点

**优点**

- 资源占用极低、启动快。
- 画质管线可调到极致（GPU + 着色器链）。
- 跨平台、开源、纯文本配置可版本化。
- lua 脚本与 IPC 可玩性/自动化极高。

**缺点**

- **无内置媒体库、默认几乎无 GUI**，新手门槛高。
- 上手靠读文档、改配置、装脚本，不是"双击就用"。
- 360 需额外装脚本，不如 VLC 内建方便。

### 适用 / 不适用人群

- **适用**：喜欢折腾、追求画质与效率、愿意写配置的进阶玩家；需要把播放嵌进脚本/流水线的人；跨平台且要一致体验的极简主义者。
- **不适用**：想要"装好就用、有好看界面和媒体库"的普通用户 → VLC/PotPlayer；偶尔看 360 不想装脚本 → VLC。

### 常见误区

- "mpv 难用=不好"——它把复杂度交给你换可控性。
- "mpv 能播 360 不用装东西"——默认不能，需脚本。
- "mpv 没有界面所以不好用"——它有屏幕控制器（OSC），纯命令行只是额外选项。

## 自查清单

- 没画面/没字幕 → 检查 `scripts\` 与 `mpv.conf` 路径、扩展名是否为 `.conf`（非 `.txt`）。
- 卡 → 开 `hwdec=auto-safe`。
- 360 是扁的 → 需装 mpv360.lua 类脚本。
- 想换机还原 → 备份 `portable_config\` 或整个 mpv 配置目录。
