# 录制与推流软件 · 总览

> 把"画面与声音采进来"的一类工具：录屏做**素材**、推流做**直播**。与 [剪辑与调色](/contents/软件/视频/剪辑与调色/总览.md) 的边界——OBS 这类是**采集 / 直播制作前端**，成片交给 DaVinci / PR 后期；它不剪辑。直播**工艺**（机位、互动、节奏）在摄像板块的直播分组，本栏只做工具选型。信息核对时点：**2026-08**。

## 角色拆分

| 角色 | 干什么 | 代表工具 |
| --- | --- | --- |
| 录屏 / 采集 | 把屏幕 / 游戏 / 摄像头变成视频文件 | OBS、Bandicam、ShadowPlay |
| 直播推流 | 实时合成多路画面并推到平台 | OBS、Streamlabs、XSplit |

多数创作者两者都要：先录素材进剪辑，或一边直播一边留档。OBS 一个软件同时覆盖两者，是默认起点。

## 工具对比

| 维度 | OBS Studio | Streamlabs Desktop | Bandicam | XSplit | NVIDIA ShadowPlay |
| --- | --- | --- | --- | --- | --- |
| 定位 | 免费开源全能 | 直播向（OBS 衍生） | Win 轻量录屏 | Win 直播套件 | 显卡录屏（仅 N 卡） |
| 授权 | 免费 / 开源 | 免费（有付费层） | 付费（免费版带水印/限时） | 订阅 | 免费（需 N 卡） |
| 跨平台 | Win / macOS / Linux | Win / macOS | 仅 Win | 仅 Win | 仅 Win（N 卡） |
| 场景 / 源 | 强（无限场景） | 强（模板多） | 弱（单源为主） | 强 | 弱（游戏/桌面） |
| 推流 | 强（全协议） | 强（平台集成好） | 弱 | 强 | 无 |
| 资源占用 | 中（可调） | 偏高 | 低 | 中 | 低（硬件） |

- **OBS Studio**：免费、开源、跨三平台、场景/源/多轨音频/插件全有，录屏与推流通吃；缺点是上手比一键录屏陡。
- **Streamlabs Desktop**：基于 OBS 内核、直播模板与平台集成更省心，但更重、有付费功能层， macOS 版功能略少。
- **Bandicam**：Windows 下最轻量的"按一下就录"，游戏/屏幕/摄像头都行，但免费版带水印且限时，功能浅。
- **XSplit**：Windows 直播套件，场景与推流体验好，但需订阅解锁完整功能。
- **NVIDIA ShadowPlay（即时重放）**：N 卡专用、几乎零性能损耗的"后台常录 + 即时回抓"，仅游戏/桌面，不能推流、不能多源合成。

> 选谁：要免费全能、录屏 + 直播都要 → **OBS**；只想一键轻量录屏（且不在乎水印）→ Bandicam；N 卡玩家想零损耗抓高光 → ShadowPlay；直播想更省心模板 → Streamlabs。

## 工作流定位

```
屏幕/游戏/摄像头 → OBS 采集（多场景合成 / 多轨音频）→ 录制文件 → DaVinci/PR 剪辑
                                              └────────────────→ 推流到 直播平台
```

- 录制素材：教学 / 游戏 / 会议 / 产品演示，录完进剪辑。
- 直播推流：实时合成画面 + 互动，边播边留档（同时录本地）。
- 与剪辑互补：OBS 出"原材料"，剪辑出"成片"，分工明确。

## 对比维度小结

| 场景 | 首选 | 关键判断 |
| --- | --- | --- |
| 免费全能 / 跨平台 | OBS Studio | 录屏 + 推流一体、开源 |
| 一键轻量录屏（Win） | Bandicam | 简单、低占用 |
| N 卡高光抓取 | ShadowPlay | 零损耗、即时重放 |
| 直播更省心 | Streamlabs | 模板 / 平台集成 |
