# OBS Studio

> 免费、开源、跨平台的"录制 + 直播推流"全能前端：实时采集屏幕 / 游戏 / 摄像头 / 采集卡，多场景合成，多轨音频，推到任意平台。客观为主，个人长期使用观察补充。信息核对时点：**2026-08**（稳定线 v32.2.x，最新版见官网 obsproject.com）。

## 概览

| 能力 | 说明 |
| --- | --- |
| 平台 | Windows 10/11、macOS 13+、Linux（Flatpak / Ubuntu PPA）；x86-64 与 Apple Silicon |
| 授权 | 免费、开源（GPL-2.0-or-later），无广告、无水印、无录制时长限制 |
| 本职 | 实时音视频采集 + 场景合成 + 录制 + 推流（RTMP / HLS / SRT / RIST / WebRTC） |
| 场景 / 源 | 显示捕获、窗口捕获、游戏捕获（Win）、摄像头 / 采集卡、浏览器、图片、文本；无限场景 + 自定义转场 |
| 音频 | 每源独立混音与滤镜（噪声门 / 降噪 / 增益）、VST 支持、多轨录制（AAC / Opus） |
| 编码器 | x264 / NVIDIA NVENC / Intel QuickSync / Apple / AMD AMF → H.264 / HEVC；可自定义 FFmpeg 输出 |
| 制作辅助 | Studio Mode（直播前预览）、Multiview（监看 8 路）、全局热键、可停靠 Dock UI、插件（原生 + Lua / Python） |
| 推流 | YouTube / Twitch / 抖音 / B 站等任意 RTMP 目标 |

一句话：它不追求"一键录完即成品"（那是 Bandicam），也不做剪辑（那是 DaVinci / PR）；追求"把多路画面和声音自由合成，再录或推"的最大控制权。

## 获取与安装

### 官方下载

- **官网**：[obsproject.com](https://obsproject.com) 直接下载，无需注册；三平台安装包齐全，按系统选（Windows 安装版 / macOS Intel 与 Apple Silicon / Linux Flatpak 或官方 PPA）。
- **版本**：稳定线 **v32.2.x**；不要碰第三方"破解 / 付费"镜像站——核心软件免费，凡是收费下载站都不是官方。
- **安装注意**：首次启动会跑**自动配置向导**（问你主做录制还是直播，再按机器与网络给分辨率 / 帧率建议），建议走完；macOS 需在系统设置里授予屏幕 / 摄像头 / 麦克风 / 辅助功能权限（辅助功能让全局热键在后台生效）。

### 系统要求与硬件编码

- **平台**：Windows 10/11、macOS 13+、主流 Linux 桌面。
- **硬件编码（吃显卡 / 驱动）**：开硬件编码能大幅降占用——NVIDIA NVENC 需较新驱动（v32.2.x 要求 NVIDIA 驱动 570+），Intel QuickSync / AMD AMF 同理保持驱动更新；老硬件或驱动旧时退回 x264 软编码。
- **资源占用**：中，可调；场景多、分辨率 / 帧率高、特效多时会明显吃 CPU/GPU，老机器录 4K/60 易卡。
- **游戏捕获（Game Capture）仅 Windows**：macOS 用"macOS 屏幕捕获"选显示器 / 窗口 / App；Linux 用"窗口捕获 / 屏幕捕获（PipeWire）"。

### 授权与成本

- **完全免费、开源（GPL-2.0-or-later）**，无广告、无水印、无订阅、无录制时长限制。
- 全功能无阉割，团队里谁装都能用。
- 成本结论：零。唯一"成本"是你可能想顺手捐给 OBS Project。

## 核心能力

### 定位与竞品坐标

- 对 **Bandicam / 系统录屏**：OBS 赢在多源合成、多轨音频、推流与跨平台、完全免费无 watermark；Bandicam 赢在"按一下就录"的轻量与低门槛。
- 对 **Streamlabs Desktop**：OBS 更轻、更可控、纯免费；Streamlabs 基于 OBS 内核、直播模板与平台集成更省心但有付费层、更重。
- 对 **DaVinci / PR**：OBS 是**采集 / 直播制作前端**，不做时间线剪辑；录完的素材交剪辑软件出成片。

**独特卖点**：**免费 + 跨平台 + 多源合成 + 录制推流一体 + 插件无限**。它是"想认真采集或直播又不想付费/被绑架"的默认项。

### 功能详述

- **场景与源**：场景是"一组画面的布局"，源是里面的元素（显示 / 窗口 / 游戏 / 摄像头 / 采集卡 / 浏览器 / 图片 / 文本）。一个场景放"全屏 + 摄像头 + 标题"，另一个只放摄像头，录制 / 直播中无缝切换，自定义转场。
- **音频混音**：每个音频源独立推子 + 滤镜（噪声门、噪声抑制、增益），支持 **VST 插件**；可录**多轨音频**（如人声一路、系统声一路、麦克风一路分开存），后期剪辑分轨处理极方便。
- **制作辅助**：**Studio Mode** 左预览 / 右直播双画布，直播前先校好再切出去；**Multiview** 单屏监看 8 路场景、单击 cue；全局热键覆盖几乎一切动作；**Dock UI** 可把面板拖成你顺手布局、甚至弹出独立窗口。
- **编码器与输出**：视频走 x264 软编码或 NVENC / QuickSync / Apple / AMF 硬件编码 → H.264 / HEVC；音频 AAC / Opus；高级用户可用自定义 FFmpeg 输出任意容器 / 编码。MKV 录制崩溃安全，事后用内置 **Remux** 转 MP4。
- **推流**：原生支持 RTMP / HLS / SRT / RIST / WebRTC，连 YouTube / Twitch / 抖音 / B 站等任意 RTMP 目标；可同时"推流 + 本地录制"留档。

### 工作流定位

OBS 适合做创作者的**采集与直播制作前端**：

```
屏幕/游戏/摄像头 → OBS（多场景合成 + 多轨音频）→ 录制文件 → DaVinci/PR 剪辑
                                        └────────────────→ 推流到 直播平台
```

- 录素材：教学 / 游戏 / 会议 / 产品演示，录完进剪辑。
- 直播：实时合成画面 + 互动，边播边录本地备份。
- 与剪辑互补：OBS 出"原材料"，剪辑出"成片"，分工明确。

## 上手与使用

### 常用快捷键

> 以下为桌面版默认键位（可在 `设置 → 快捷键` 重映射，并支持全局热键）。

| 场景 | 快捷键 | 作用 |
| --- | --- | --- |
| 录制 | `Start/Stop Recording` 默认无（建议自定） | 开始 / 停止录制 |
| 推流 | `Start/Stop Streaming` 默认无（建议自定） | 开始 / 停止推流 |
| 回放缓冲 | `Replay Buffer` 相关 | 即时重放（需先开回放缓冲） |
| 场景 | `Ctrl+Alt+[1-9]` 或自定 | 切换到指定场景 |
| 场景 | `Ctrl+[` / `Ctrl+]` | 上一个 / 下一个场景 |
| 转场 | `Ctrl+T` 或自定 | 应用快速转场 |
| 音频 | `Ctrl+Shift+M`（源静音，自定） | 静音切换指定源 |
| 音频 | `Ctrl+↑` / `Ctrl+↓`（源音量，自定） | 音量 ± |
| 预览 | `Studio Mode` 自定 | 进入 / 退出工作室模式 |
| 视图 | `全屏预览` 自定 | 全屏监看 |

> 提示：OBS 默认**未绑定**开始/停止录制与推流的热键，首次用务必在 `设置 → 快捷键` 里设好（尤其全局热键，方便后台控）。

### 常用技巧

- **跑自动配置向导**：首次启动选"录制"或"直播"，让它按机器给分辨率 / 帧率建议，再微调。
- **加源**：`源` 面板点 `+` → 显示捕获（全屏）/ 窗口捕获（某 App）/ 游戏捕获（Win 游戏）/ 视频捕获设备（摄像头 / 采集卡）/ 浏览器（ overlay / 网页）。
- **输出设置（关键）**：`设置 → 输出`：编码器优先硬件（NVENC / QuickSync / AMF），录制格式选 **MKV**（崩溃安全）再 Remux 成 MP4；帧率 30 够多数教程/演示，60 适合快动作但更吃资源；勾"每源独立音轨"做多轨音频。
- **多轨音频分离**：在音频高级设置里把麦克风、系统声、其他源分到不同轨，后期剪辑分别调。
- **直播前用 Studio Mode**：左边改好下一镜、右边是当前直播画面，确认无误再切，避免把"半成品"播出去。
- **推流对接**：`设置 → 直播` 选平台（或自定义 RTMP），填服务器与推流密钥；建议同时开"推流时录制"留本地备份。
- **MKV 转 MP4**：`文件 → Remux 录制` 把 .mkv 安全转成剪辑软件友好的 .mp4，避免断电/崩溃丢素材。

### 使用体验速记

> 以下为长期使用观察（待你按真实体验校订）：第一次会劝退——要先想清楚场景/源/音频路由/编码器；一旦搭好一套场景模板，日常录教程/游戏/会议非常顺，多轨音频是后期大救星；硬件编码开起来老机器也稳，关了或驱动旧就卡；插件有时随 OBS/系统升级失效，需注意版本。

## 适用人群与误区

### 优缺点

**优点**

- 免费、开源、跨三平台、全功能无阉割、无水印无时长限制。
- 多源合成自由度高，场景/转场/Studio Mode/Multiview 专业。
- 多轨音频 + VST，采集即"分轨素材"，后期友好。
- 录屏与推流一体，硬件编码降低占用。
- 插件 / 脚本生态丰富，可深度定制。

**缺点**

- 上手比一键录屏陡（场景 / 源 / 音频路由 / 编码器要学）。
- 不是剪辑软件，录完仍需进 DaVinci / PR 出成片。
- 场景多 / 高参数时占资源，老硬件会卡。
- 插件可能随 OBS 或系统更新失效。

### 适用 / 不适用人群

- **适用**：要录教学 / 游戏 / 会议 / 产品演示的人；要做直播（多路画面合成 + 互动）的人；跨平台团队；想要免费专业采集的人。
- **不适用**：只想一键轻量录屏、不愿学 → Bandicam / 系统自带；录完要直接出精剪成片 → 交给 DaVinci / PR；Mac 上要"游戏捕获"那种低开销抓游戏 → OBS 在 macOS 走屏幕捕获，游戏内捕获支持有限。

### 常见误区

- "OBS 能剪辑"——不能，它是采集 / 直播前端，剪辑交给 DaVinci / PR。
- "只有直播才用 OBS"——录屏做素材同样主力，很多教程视频都它录的。
- "官方要付费"——核心软件永久免费开源，凡是收费下载站都是仿冒 / 镜像。
- "开硬件编码一定更好"——驱动旧或配置错反而出问题，老机器可退回 x264。

## 自查与延伸

### 自查清单

- 录制卡 / 掉帧 → 降分辨率 / 帧率，或开硬件编码（先更新显卡驱动）。
- 没声音 → 检查音频源是否添加、桌面音频与麦克风是否静音、音量推子。
- 推流连不上 → 核对服务器地址与推流密钥、网络上行带宽、平台是否开启直播。
- 断电 / 崩溃丢素材 → 录制用 MKV，事后 Remux 成 MP4。
- 直播播出半成品 → 用 Studio Mode 先预览再切。
