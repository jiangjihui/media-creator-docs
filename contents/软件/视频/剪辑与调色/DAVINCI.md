# DaVinci Resolve

> 一站式专业后期：剪辑、节点调色、Fusion 合成、Fairlight 音频全在一个工程里走完。本文定位为**技能知识库**——既讲清"它是什么、怎么选"，也给出可照做的剪辑/调色/合成/音频工作流与一份经筛选的学习资源地图。客观为主，个人长期使用观察补充。信息核对时点：**2026-08**（主版本 Resolve 20，免费版与 Studio 买断并存）。

## 概览与产品定位

| 页面 | 能力 | 备注 |
| --- | --- | --- |
| 媒体（Media） | 导入、转码、克隆备份、代理生成、媒体池管理 | 工程入口，所有素材先到这里 |
| 快编（Cut） | 高速粗剪、双时间线、智能插入、竖屏重构 | 为"时间紧"而生，比 Edit 页更顺手的快剪台 |
| 剪辑（Edit） | 精细时间线、转场、字幕、多机位、特效、自动转录 | 传统 NLE 时间线，复杂项目主力 |
| Fusion | 节点合成、特效、动态图形、3D、粒子 | 原独立合成软件，内嵌为页 |
| 调色（Color） | **节点式调色**、LUT、一级/二级、遮罩跟踪 | 行业标杆，好莱坞调色台同源 |
| Fairlight | 多轨音频、混音、降噪、ADR、杜比全景声 | 原独立音频软件，内嵌为页 |
| 交付（Deliver） | 多格式导出、渲染队列、预设、HDR/广色域 | 成片出口 |

一句话：它不是一个"剪辑软件带点调色"，而是**四个原本独立的专业软件 + 一个媒体管理器**被收进同一套工程。这也是它上手重、但一旦熟悉就难以离开的原因。

### 与其他软件的较量

- 对 **Premiere Pro**：Resolve 把调色/合成/音频也内化，少切软件；PR 强在 Adobe 全家桶联动与团队协作、插件生态更成熟。
- 对 **Final Cut Pro**：两者都走"买断/免费"路线，Resolve 跨平台（Win/Mac/Linux），FCP 仅 macOS；FCP 磁吸时间线更"苹果化"。
- 对 **剪映**：Resolve 深度与画质上限高数个量级，代价是学习成本；剪映胜在模板与效率，适合当天出片。

### 独特卖点：节点调色

图层式调色（PR/FCP）像叠滤镜——效果按顺序糊在画面上，想"只对天空做对比度而不溢出地面"要靠蒙版硬切。节点式（Resolve）像搭**信号链**：每个节点是一个处理单元，可串行、可并行、可复制复用。复杂调色下可控性碾压，也是它被称为"调色标杆"的根本原因。

### 学习曲线真相

面板多、信息密度高，新手前几周有"劝退期"；节点概念陌生；首次遇到 4K 卡顿易挫败。**但这是可跨越的曲线，不是墙**——先用 Cut 页剪完一条片子建立成就感，再进 Color 页学一级校正，用到 Fusion/Fairlight 再补。详见下方「学习资源地图」与「效率体系」。

- **平台**：Windows / macOS / Linux 全支持（少数跨平台专业后期之一）。

- **硬件加速解码**：开启后可显著降低回放卡顿；Windows 下部分格式默认走 CPU 解码，需手动开启。
- **磁盘**：优化媒体/代理会占用额外空间，建议素材盘、缓存盘、系统盘分离。

## 剪辑与交付

### 两大剪辑页：Cut 与 Edit

- **Cut 页**：为"快"设计。双时间线（源 + 时间线并排）、智能插入、源磁带模式、竖屏重构（把横屏 16:9 快速改 9:16 发短视频）、Dynamic Zoom（一键 Ken Burns 式推拉）。适合粗剪、日更、社媒。
- **Edit 页**：传统 NLE 时间线，轨道多、工具全，转场/字幕/多机位/特效/音频精修都在这里。复杂项目、精细剪辑的主力。

经验：先用 Cut 把结构定下来，再切 Edit 做精修与特效，是最高效的组合。

### 核心剪辑操作

- **三点编辑**：在源监视器设入/出点（I/O），在时间线设第三个点，插入/覆盖。最稳的精准剪辑法。
- **修剪（Trim）**：波纹（ripple）、滚动（roll）、滑移（slip）、滑动（slide）四种；Resolve 20 强化了实时动态修剪。
- **多机位**：媒体池里把多机位素材按时间码/音频同步成多机位剪辑，时间线上切角度，演唱会/访谈神器。
- **自动转录（Resolve 20）**：对项目跑自动转录生成文字稿，可在文字上直接删词、改顺序来剪片子——"文本即时间线"，访谈/口播效率倍增。
- **标记与跳转**：`M` 打标记；Edit 页 `↑/↓` 跳到上/下一段剪辑，快速导航长时间线。

### 代理与优化媒体（流畅剪辑的命脉）

高压缩素材（H.264/H.265、手机/无人机直出）在中端机上直剪必卡，解法不是换电脑，而是**降码率代理**：

- **代理模式（Proxy Mode）**：`Playback → Proxy Mode` 开启后，Resolve 后台把 4K 转成低分辨率轻量临时文件供剪辑，导出时自动换回原素材——画质无损、剪辑丝滑。
- **优化媒体（Optimized Media）**：右键片段 → `Generate Optimized Media`，把难啃的格式预转成 ProRes/DNxHR 这类剪辑友好格式；特效多的工程尤其稳。
- 两者都占额外磁盘，建议代理/优化盘独立。

### 交付与输出

- **预设优先**：交付页内置 YouTube / Vimeo / H.264 / H.265 / ProRes 等预设，按平台选好再微调，别手填编码参数。
- **渲染队列**：可排队多分辨率/多平台导出，挂机批量出片。
- **HDR 与广色域**：支持 Rec.709 / Rec.2020 / Dolby Vision 等，配合工程色彩管理输出，确保跨设备观感一致。
- **单个片段 vs 整条时间线**：可只渲染入/出点区间或指定片段，迭代预览更快。

## 节点调色

调色是 Resolve 的"名片"，也是它区别于图层式工具的核心。下面给出可照做的工作流。

### 为什么要节点

图层式（PR/FCP）：效果按顺序堆叠，想局部处理要靠蒙版硬切，复杂场景节点爆炸。
节点式（Resolve）：每个节点是一个处理单元，信号从左到右流动，可**串行**（A→B→C 依次处理）、可**并行**（多路汇入层混合器 Layer/Mix），可复制复用。结果：结构清晰、改一处不牵动全局。

### 节点树基础

- **串行节点**：默认新建的节点串成一条链，前一个的输出是后一个的输入（例如：平衡 → 肤色 → 天空 → 风格化）。
- **并行 / 层混合（Layer Mixer）**：把两条串行链的结果按透明度叠合，常用于"调好的底图 + 局部强化层"。
- **添加节点**：在节点图空白处双击加串行节点；右键 → Add Node 可选并行/层混合/外部节点。

### 一级校正（先平衡，再风格）

- 用**示波器**做客观判断：波形（亮度）、 parade（RGB 分量）、矢量示波器（色相/饱和度）、直方图。
- 动作：先用 Lift/Gamma/Gain（或色轮）把画面**曝光与白平衡拉平**，让不同机位/光比镜头彼此匹配——这是"一级"的目标，不是好看，是"一致"。
- 原则：先整体后局部、先还原后风格。

### 二级校正（只动该动的地方）

- **限定器（Qualifier）**：按亮度/色相/饱和度抠出某类像素（如天空、肤色），再单独调。
- **Power Window**：画圆/矩/多边形/曲线窗口圈定区域，配跟踪让它跟着画面走。
- **Magic Mask（AI）**：自动识别主体/物体并生成遮罩、自动跟踪，二级调色与抠像效率极高。
- **跟踪（Tracker）**：让窗口/遮罩锁定运动物体，省去逐帧手调。

### 色彩管理（别再裸调）

"裸调"容易调完发灰、跨软件不一致。正确做法是用**色彩管理**统一管线：

- **Resolve Color Management（RCM）**：在项目设置里选输入色彩空间（相机 LOG/RAW）→ 时间线工作空间 → 输出（如 Rec.709）。Resolve 自动在节点链首尾做转换。
- **CST（Color Space Transform）节点**：手动在节点链里插入转换节点，精细控制每一段在哪套色彩空间里工作，灵活度高于全局 RCM。
- **ACEScct**：电影工业常用的跨设备色彩管线，追求院线一致性时选用。
- **LUT vs CST**：LUT 是"烘焙好的查表"，快但不透明、易断层；CST/色彩管理是"可逆的数学转换"，更可控。新手可用 LUT 找方向，成品建议走 CST。

### Color Warper 与 Color Slice

- **Color Warper**：在"色相 × 饱和度"网格上直接拖拽变形，做精细的饱和度/色相重塑，比传统曲线更直观。
- **Color Slice**：按"肤色/天空/植被"等语义切片调色，针对特定自然色彩做保护式调整，避免牵一动百。

### 节点预设与工作流沉淀

- 把调好的节点树存进 **Gallery（调色画廊）** 作静帧/预设，跨项目一键套用，逐步沉淀自己的"风格库"。
- 团队可共享 PowerGrade（.drx），统一品牌调色基线。

## Fusion 合成与 Fairlight 音频

### Fusion 节点合成

Fusion 是 Resolve 内的节点合成引擎，复杂特效不用离开软件去开 AE：

- **Merge 节点**：把前景（含 Alpha）合成到背景，是合成的基本单元。
- **抠像**：Delta Keyer（主流绿幕/蓝幕）、Luma Keyer（亮度抠像，如换天空）、3D Keyer；配合 Clean Plate 去溢色。
- **跟踪**：Point Tracker（点位）、Planar Tracker（平面跟踪，稳定/替换屏幕内容）。
- **3D 与粒子**：Fusion 有真 3D 工作区（相机/灯光/物体），Advanced VFX 指南（Studio）覆盖 3D 摄像机跟踪、USD、粒子。
- **何时用**：片头动态图形、绿幕合成、画面修复、简单特效——都可在 Fusion 页内完成。

### Fairlight 音频

成片音频不必出软件：

- **混音**：多轨对齐、声像、母线（bus）分组、自动化（automation）记录推子运动。
- **EQ 与动态**：均衡器雕形、压缩/限制器控动态，对人声去"闷"、去"刺"。
- **降噪**：噪声降低（Noise Reduction）处理底噪；配合 EQ 修对白。
- **ADR 与 Foley**：录制旁白/对白替换、拟音；Track Layers 把多镜次叠成理想结果。
- **杜比全景声（Dolby Atmos）**：Fairlight Immersive 工具做沉浸式混音（需相应工程设置与输出授权）。

### 实战技巧

- **代理模式（Proxy Mode）**：菜单 `Playback → Proxy Mode` 开启，中端机也能丝滑剪 4K，画质无损。
- **优化媒体（Optimized Media）**：右键片段 → `Generate Optimized Media`，把 H.264/H.265 预转成 ProRes/DNxHR；特效多的工程尤其稳。
- **节点预设复用**：把调好的调色节点树存进 **Gallery** 作预设，跨项目一键套用，沉淀自己的"风格库"。
- **色彩管理**：项目设置里选对 Color Science、输入色彩空间与输出（如 Rec.709 / ACEScct），避免"调完发灰、跨软件不一致"。
- **开启硬件解码**：偏好设置 → 解码 → 勾选"使用 GPU 解码 H.264/HEVC"，显著降低回放占用。
- **渲染队列**：交付页排队多分辨率/多平台导出，睡前挂机批量出片。
- **配置备份**：键盘映射、Gallery 预设、PowerGrade 可导出，换机一键还原。
- **自动保存与版本**：依赖自动保存之余，关键节点手动存工程版本（Project → 版本）。

### 使用体验速记

> 以下为长期使用观察（待你按真实体验校订）：启动与工程加载偏重，但一旦节点流程搭好，调色效率与可复用性远超图层式工具；免费版足以撑起个人商单；4K H.265 直剪在中端机必开代理；Studio 的多 GPU 与高阶降噪在 8K/噪点素材上才显价值。配置文件（键盘映射、Gallery 预设）可导出备份，换机一键还原。

## 适用人群、误区与自查

### 优缺点

**优点**

- 免费版即专业级，调色能力行业天花板。
- 四合一，少切软件、工程不丢上下文。
- 买断制（Studio），无订阅焦虑；跨平台。
- 节点式调色可控性极强，可复用流程。

**缺点**

- 面板多、信息密度高，新手前几周有"劝退期"。
- 对硬件（尤其 GPU/解码）要求高，低配机需代理救场。
- 团队协作/插件生态成熟度略逊 PR+AE。
- 部分高阶 AI/编码/分辨率需 Studio。

### 适用 / 不适用人群

- **适用**：想认真学一门用到老的手艺的人；调色/影视为核心的创作者；追求买断与跨平台的人；小团队一站式后期。
- **不适用**：只想当天出片、要模板懒得学 → 选剪映；已在 Adobe 全家桶深度协作、依赖 AE 联动 → 选 PR；纯 Mac 原教旨且只剪不调色 → FCP 更顺手。

### 常见误区

- "免费版不够用"——对 90% 个人创作者已够。
- "达芬奇只能调色"——它是四合一，剪辑/合成/音频都能做。
- "卡就是电脑不行"——多半是没开代理/硬件解码。
- "必须买 Studio 才专业"——免费版已能交付商业成片。
- "节点太难学不会"——先把一条串行链跑通（平衡→肤色→风格），自然就懂了。

### 自查清单

- 素材是 H.264/H.265 高压缩？是 → 默认开代理。
- 要调色协作 / 电影级输出？→ Studio 值得。
- 只在手机发短视频？→ 剪映更省事；若坚持 Resolve，用 Cut 页 + 竖屏重构最快。
- 频繁换机/团队协作？→ 导出键盘映射与 Gallery 预设备份；考虑 Blackmagic Cloud 工程。
- 调色老发灰/跨软件不一致？→ 改用 RCM/CST 色彩管理，别裸调。
