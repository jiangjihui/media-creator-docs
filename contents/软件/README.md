# 软件 · 总览

> 「软件」与「设备」（硬件）互补：硬件一次买断用多年，软件订阅按年付费——选型逻辑因此不同：软件看**工作流匹配度、生态锁定与持续成本**，而不是堆参数。与[学习资源 · 常用工具链接](/contents/学习资源/常用工具链接.md)的边界：这里放「怎么选」的正文，那边只放链接清单。

## 分类逻辑

软件按 **「媒体类型 → 角色 →（总览 + 工具）」** 三级组织：

- **媒体类型**：视频 / 音频 / 图片（暂不扩 3D、字幕）。录制与推流工具（含直播推流选型）归入「视频」；直播**工艺**本身在 [摄像/直播](/contents/摄像/)，本栏只做工具选型。这是创作者选工具的第一直觉——"我手上是视频，需要什么"。
- **角色**：每种媒体类型下按"要干嘛"分（如视频分剪辑调色、播放）。每个角色文件夹里同时收 **`总览.md`（该角色的选型对比）** 和 **以工具命名的档案**（`DAVINCI.md` / `VLC.md` / `MPV.md`），进一个角色就能看全，不用跨层找。
- **工具档案**：单个软件的深度档案，复用「设备」栏单品档案框架并适配（见下文）。

## 跨媒体通用选型总论（规划中）

跨类型的共性规律（订阅 vs 买断、色彩管理、编解码与硬件加速、工作流串联）计划单独成篇，避免每个角色重复讲；当前尚未动笔，相关原理暂见 [摄影 · 器材](/contents/摄影/器材/相机机身.md)。

## 软件档案规范

为保证"随用随补"不走样，工具档案遵循以下约定（适配自「设备」栏单品档案，并按 2026-08-26 反馈简化）：

- **归档路径**：`软件/<媒体类型>/<角色>/<工具名>.md`（如 `视频/播放/VLC.md`）；侧栏显示文本用工具习惯名（如「VLC」「mpv」）。
- **标题层级（铁律）**：二级标题（H2）只放"性质不同的大块"，**一般 5–7 个足矣**；相似内容用**三级标题（H3）归并到同一 H2 下**（如把"系统要求""授权成本"都收进「获取与安装」）。**不要编号**（一、二…是冗余占位），也不要通篇都用 H2。
- **四级标题（H4）可用**：当某个 H3 仍较长、需要更细粒度切分时，**允许在该 H3 下用 H4**（如「常用技巧」下按场景再拆「性能调优 / 工作流提效 / 排错」）。一篇文章里出现 H4 是合理的阅读辅助层级。注意本站 `subMaxLevel: 2`——H3/H4 本就不进侧栏页内目录，只用作文正层级，不会破坏导航，放心用。
- **必含实料（比旧模板更丰富）**：除定位外，必须写清 **获取渠道（官方下载地址/版本选择）**、**常用快捷键**、**常用技巧**，避免只有概述表格。
- **模板变体**：新形态（网页工具、移动端 App）允许裁剪章节，但保留三段内核——核心能力、使用体验、适用/不适用人群。
- **推荐章节骨架（6 个 H2）**：
  1. 概览（核心能力速览表 + 一句话定位）
  2. 获取与安装（H3：官方下载渠道 / 系统要求与硬件加速 / 授权成本）
  3. 核心能力（H3：定位竞品 / 功能详述 / 工作流定位）
  4. 上手与使用（H3：学习曲线 / 常用快捷键 / 常用技巧 / 使用体验）
  5. 适用人群与误区（H3：优缺点 / 适用·不适用 / 常见误区）
  6. 自查与延伸（H3：自查清单 / 延伸阅读）
- **单一事实源**：调色/编码等原理只链接到对应栏目（如[摄影 · 器材](/contents/摄影/器材/相机机身.md)），不在本栏目重复展开。

## 与相邻栏目的边界

- `软件` = 工具"怎么选"；`摄像/影视制作/剪辑与调色` = 后期**工艺**——一个讲用哪个软件，一个讲怎么剪，不重叠。
- `软件` = 选型正文；`学习资源/常用工具链接` = 只放链接清单。
- `摄像/直播/` = 直播**工艺**；本栏的推流工具（如 OBS）只做"工具选型"，工艺留在 [摄像/直播](/contents/摄像/)。
