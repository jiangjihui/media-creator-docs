## 边界

- 本子栏目**不讲**响度与编码原理（在 [声音设计](/contents/摄像/影视制作/声音设计.md)）、**不重述**"发完怎么读数据"（在 [数据分析](/contents/自媒体运营/数据分析.md)）、**不替你决定**做什么内容（在 [内容策划](/contents/自媒体运营/内容策划.md)）。
