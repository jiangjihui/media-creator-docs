## 各平台要点

### 抖音

9:16 竖屏主场；前 3 秒定留存；码率给上沿；封面与视频同比例 1080×1920。算法对完播率与互动极敏感，结构比画质更影响分发。

### B站

16:9 横屏为主、也收竖屏；4K 给高码率（35 Mbps 档）；封面 1146×717（16:9 缩略图）；允许长视频、无时长硬限制。社区重"内容硬核度"，标题可更详细。

### 视频号

9:16；播放上限 1080P，但**传 4K 源可让平台以更高码率转码**（超分冗余技巧）；社交（微信）分发强，转发链很重要。

### 小红书

3:4 是封面友好比例（信息更全），视频也可 9:16；封面 1080×1440；社区偏图文，封面与标题极重要，搜索权重高。

### YouTube

16:9；Shorts 走 9:16 竖屏独立入口（≤3min）；封面 1280×720；国际化，标题含英文关键词有搜索收益；长视频无时长限制。

## 一稿多投

同一份内容想铺多个平台，靠"母版 + 比例派生"而非重剪：

- **三种比例覆盖**：9:16（抖音 / 视频号 / Shorts / 快手）、1:1（部分信息流）、16:9（B站 / YouTube 横屏）。构图时预留安全中心区，方便裁切。
- **母版派生改法**：从母版缩放 / 裁切，不重剪时间线——详见 [母版与交付规格](母版与交付规格.md)。
- **只改尺寸封面文案不改内容**：16:9 拍的，竖屏版裁中间、加平台字幕 / 封面，正文不动。

## 参数为什么会变

- 平台会随设备 / 政策改推荐规格（典型如 Shorts 时长从 60s 放宽到 3min）。
- **去哪查最新**：各平台「创作者中心 / 帮助中心 / 创作规范」官方文档；直接搜"平台名 + 视频上传规格 / 要求"。
- 比死数字更有长期价值的是三原则：**匹配源 + 留冗余 + 看官方**。

## 自查清单

- 自查：比例对了吗？码率在上沿吗？封面尺寸对吗？是按官方最新核的吗？
- 常见误区：用同一份 16:9 硬塞竖屏平台（上下黑边）；信单一 SEO 站的旧数字。
