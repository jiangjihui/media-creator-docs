# 作品复盘

> 本子栏目是「拍完后的作品复盘 / 评析」，**不是拍摄技法教程**——技法教程在 [摄影 · 题材实战](/contents/摄影/题材实战/) 与 [影视制作](/contents/摄像/影视制作/)。
> 复盘回答的问题是：这张照片 / 这部片子好在哪、差在哪、下次怎么改——以成片为对象，倒推回技法与决策。

## 与教程的分工

教程告诉你「应该怎么拍」，复盘检验「实际拍成了什么」。两者对照阅读收获最大——发现问题时，回到对应技法文章找原因（页面里已内嵌回链）。

> **说明**：复盘页的「填表示范」小节中的作品与数据为**方法演示而构造的合成示例**，不是作者真实作品，仅用于示范表格怎么填。

> **延伸**：想直接看"怎么拍"的教程，去摄影 · 题材实战；想看"怎么交出去"，去 [导出与分发](/contents/交付与复盘/导出与分发/)。
