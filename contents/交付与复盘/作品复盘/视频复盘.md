# 视频复盘

> 说明：本页「填表示范」小节中的作品与数据为**方法演示而构造的合成示例**，不是作者真实作品的复盘记录，仅用于示范表格怎么填、结论怎么落到动作。你自己的作品请按「模板与归档」里的空模板填入。

> 一句话：**视频复盘最容易踩的坑，是把"分发问题"当成"片子问题"去改**——先分清作品分和数据分，再动手。

## 作品分与数据分

视频复盘要打两套分，而且**两套分要分开看**：

| 情形 | 真实结论 |
| --- | --- |
| 作品分高 + 数据高 | 提炼可复用结构 |
| **作品分高 + 数据低** | **分发问题**：查封面 / 标题 / 发布时机，别改片子 |
| 作品分低 + 数据高 | **标题党风险**：流量留不住人，看转粉率 |
| 作品分低 + 数据低 | 回到前期策划，别在剪辑上磨 |

> 看到"作品分高、数据低"就重剪片子，是最高频的无效努力——封面货不对板、标题没关键词，剪得再好也白搭。

## 作品分六维度

| 维度 | 权重 | 5 分判据 | 1 分判据 |
| --- | --- | --- | --- |
| **目标达成** | 25 | 开头承诺的看完实现了 | 看完不知道讲了啥 |
| **结构与钩子** | 20 | 前 3 秒给继续看的理由 | 开场 10 秒还在铺垫 |
| **节奏与信息密度** | 20 | 不拖、信息有密度 | 大量空镜 / 废话 |
| **画面** | 15 | 稳、曝光对、统一 | 晃、糊、跳帧 |
| **声音** | 10 | 干净、人声清楚 | 底噪大、听不清 |
| **包装与交付** | 10 | 字幕 / 转场 / 规格对 | 错别字、比例错 |

**分数怎么用**：同摄影复盘——≥4.2 可交付，最低分项单独改，分数只在同类题材间可比。

## 结构复盘

留存曲线是结构复盘最直观的武器：横轴时间、纵轴"还在看的人占比"。哪一段掉得狠，问题就在哪一段。

**留存曲线六形态诊断**：

| 曲线形态 | 归因 | 改法 |
| --- | --- | --- |
| 0–3s 断崖（掉 >45%） | 钩子失效 / 货不对板 | 钩子写法见 [短视频脚本与钩子结构](/contents/摄像/短视频/短视频脚本与钩子结构.md) |
| 3–10s 继续陡降 | 开场铺垫太长 | 把结论前置 |
| 中段平台（缓降） | 正常 | — |
| 中段陡降 | 信息密度低 / 节奏拖 | 加中段小钩子 |
| 结尾前回升 | **好信号**：有返看 / 检索价值 | 强化"值得收藏"的信息点 |
| 结尾掉光 | 结尾无行动指引 | 补行动结尾 |

**节奏量化四件套**：平均镜头时长 ASL（快剪 1–2s / Vlog 2–4s / 口播 3–6s / 抒情 6s+）· 信息密度（教程 3–5 个/分）· 素材成片比（健康 ≥2.5:1）· 静默长度（>1.5s 即剪）。

## 五轨技术检查

把技术瑕疵按五个轨道逐一过，避免"看着哪都不对"却找不到点：

- **画面**：构图稳不稳、曝光对不对、全片影调是否统一、有无跳帧/穿帮。
- **声音**：底噪大不大、人声是否清楚、音乐是否压过人声（响度与混音原理见 [声音设计](/contents/摄像/影视制作/声音设计.md)）。
- **色彩**：全片白平衡/影调一致，无突兀偏色。
- **字幕包装**：字幕在安全区、无错别字、字体大小统一。
- **导出交付**：规格对平台（比例/码率/封装见 [母版与交付规格](/contents/交付与复盘/导出与分发/母版与交付规格.md)）。

## 数据复盘

数据分看四件套，基准值只引用不重算，每条跟回链：

| 指标 | 健康基准 | 低了看什么 | 回链 |
| --- | --- | --- | --- |
| 3 秒留存率 | ≥55% | 封面 / 钩子 | 短视频脚本与钩子结构 |
| 完播率 | ≥70%（15s 视频 ≥40%） | 节奏 / 中段钩子 | [数据分析](/contents/自媒体运营/数据分析.md) |
| 互动率 | ≥3% | 内容是否有共鸣点 | 数据分析 |
| 转粉率 | ≥1% | 人设 / 价值是否清晰 | 数据分析 |

> 基准会因平台与题材浮动，且会随时间变化——需要时回数据分析看最新口径，别把数字当铁律。

## 填表示范

> 以下为**合成示例**，用于示范填写；非真实作品。

**信息卡**：一条 60 秒教程片 / 口播 + 屏幕录制 / 手机拍摄 / 发布抖音 + B站。

**作品分**：目标达成 4 / 结构与钩子 3 / 节奏 4 / 画面 4 / 声音 3 / 包装 4。
**数据分**：3 秒留存 48% / 完播 35% / 互动 2.1% / 转粉 0.6%。

**诊断**：作品分高（3.7）+ 数据低 → 这是**分发问题**，不是片子问题。3 秒留存掉到 48%（低于 55%），典型"封面货不对板"——封面是静态软件截图，没让人想点。

**唯一动作**：重做封面（人物出镜 + 结论前置如"3 步搞定导出"），标题补"3 步"数字钩子；片子本身只微调开头 2 秒。

> 你怎么填：先判"作品分 / 数据分"四象限，再决定改片子还是改分发；数据项照搬你后台真实数字，别套用本例。

## 自查清单

- 自查：作品分和数据分分开打了吗？留存掉点定位到时间轴了吗？五轨逐项过了吗？动作可验证吗？
- 常见误区：作品分高数据低却去重剪；拿不同题材完播率横比；把平台基准当绝对值。
