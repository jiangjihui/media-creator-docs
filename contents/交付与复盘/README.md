# 交付与复盘

> 本板块管创作闭环里**相邻的两段**：把作品**交付**出去（导出、按平台规格、做封面标题），再回过头**复盘**它（好在哪、差在哪、下次怎么改）。前面「摄影 / 摄像 / 设备 / 软件」讲"怎么造"，这里讲"造完之后怎么交、怎么看"。

```mermaid
flowchart LR
    A["创作<br/>拍摄 / 剪辑"] --> B["导出与分发<br/>多平台交付"]
    B --> C["作品复盘<br/>评析与归因"]
    C --> D["再创作<br/>改法落到下次"]
    D --> A
```

> 一句话：**交付让作品被看见，复盘让下一次更好看**——两段缺一不可，跳过分发等于白做，跳过复盘等于白拍。

## 边界

- 本板块**不重述技法**：导出参数怎么定只讲"查什么"，响度/编码原理回链 [声音设计](/contents/摄像/影视制作/声音设计.md)；复盘只给"判据"，改法回链对应技法页。
- 与教程的分工：教程讲"应该怎么拍"，复盘检验"实际拍成了什么"——发现问题时回到技法文章找原因。
