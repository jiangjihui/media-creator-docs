# 曝光与拍摄逻辑

> 胶片曝光的原理与数码同源，但**宽容度分布、反馈方式、补偿方向**完全不同：数码是"拍了就看、错了重拍"，胶片是"按下之前必须做对"。本文只讲胶片特有的曝光逻辑，光圈快门感光度的原理回链[曝光三要素](../器材/曝光三要素.md)。

## 曝光哲学与估光
### 宽容度是最大本钱

| 介质 | 可用宽容度（约） | 容错哲学 |
| --- | --- | --- |
| 数码 RAW | ±2~3EV（暗部优先） | 欠曝可拉，死黑难救 |
| 彩色负片 | **±3EV 且亮部优先** | 过曝可扫回，欠曝不可救——与数码直觉相反 |
| 黑白负片 | ±2~3EV | 同样偏"向右"，影调层次靠暗部撑 |
| 反转片 | 仅 ±0.5EV | 没有本钱可言，测准才拍 |

这张表是胶片曝光所有策略的出发点：**你买的胶卷类型，决定了你该怕什么**。彩负用户怕欠曝，反转用户怕过曝，仅此一念之差，成片率天差地别。

用同一个逆光人像场景感受差异：人物面部处于阴影、背景天空明亮，光比约 4 档。拍彩负——按脸部测光再 +1EV，天空过曝变白但脸是通透的，完全能用；拍反转——按天空测光，脸沉成剪影或补闪，按脸测则天空死白，两头只能保一头；数码 RAW——按脸测然后靠后期把高光拉回来。**同一场景三种介质的正确动作完全不同**，这就是"先认介质再谈曝光"的含义。

### 负片向右，正片向左

- **彩色负片：默认 +0.3~+1EV 拍摄**。底片密度厚一点，扫描后暗部干净、肤色通透；欠曝的彩负是"浑浊的阴影 + 死黑的脸"，扫不回来；
- **反转片：宁可欠半档**。高光一旦溢出就是不可逆的死白，按高光曝光、让暗部沉下去；
- 黑白负片跟随彩负策略略偏保守（+0.3EV 级别即可），给放大和扫描留中间调。

实操口径：机身有曝光补偿就拨 +0.7 或 +1；没有补偿功能的老机身，把 ISO 拨盘手动降一档（400 卷拨到 320/250），等效整体加曝。这个技巧同样服务于[迫冲](胶片种类与选择.md)——只是方向相反。

一个反直觉的提醒：**"向右"不是无脑过曝**。彩负 +1EV 是甜点位，继续往上 +2~3EV 颗粒会因放大提亮而重新变粗、高光色彩信息开始丢失。补偿是策略不是信仰，甜点区间就半档到一档半。

### 阳光十六法：估光兜底

全机械机没电池、或怀疑机身测光时，这套口诀能让你不插电完成 90% 的白天拍摄：

| 光照条件 | 光圈基准 | 典型场景 |
| --- | --- | --- |
| 雪地/沙滩强反光 | f/22 | 大面积白色反射环境 |
| **烈日晴天** | **f/16** | 正午前后、影子清晰的天气 |
| 薄云遮日 | f/11 | 影子发虚但仍可见 |
| 多云 | f/8 | 影子很淡 |
| 阴天/开阔阴影 | f/5.6 | 树荫下、楼阴里 |
| 浓阴/深阴影 | f/4 | 乌云密布、屋檐深处 |

使用方法两步：①按上表定光圈；②快门取 **1/ISO**（ISO 200 → 1/250s 附近，ISO 400 → 1/500s）。

口诀速记版："**艳阳十六，阴天八，多云十一日初落；华盖五点六，雨雪四来凑**"——背下来比翻表快。

第三步是**主体修正**——光照表描述的是环境，主体朝向和颜色还要再调：

| 主体情况 | 修正量 |
| --- | --- |
| 正面受光（顺光） | 基准值不动 |
| 侧光（半明半暗） | 开大一档 |
| 逆光拍亮部细节 | 开大两档 |
| 逆光拍剪影 | 按背景亮部曝光，不开大 |
| 主体为深色（穿黑衣）/浅色（白墙前） | 相应开大 / 收小一档 |

与手机测光 App 互相校验几次，你对光线的直觉会以肉眼可见的速度进步——估光的终点不是替代测光器，而是让你在按下快门前就知道大概会是什么影调。

### 测光陷阱：机器会被什么骗

机身测光把世界当灰色（18% 反射率）处理，所以**大面积的白和黑都会骗过它**：

| 场景 | 机器倾向 | 正确动作 |
| --- | --- | --- |
| 雪景 / 海滩 / 白墙前 | 认为环境很亮 → 欠曝 → 雪变灰 | 在测光基础上 +1.5~2EV |
| 逆光人像 | 按背景测 → 主体死黑 | 凑近对脸测光锁定，或 +2EV |
| 夜景霓虹 / 舞台追光 | 大面积黑 → 过曝 → 灯牌糊掉 | 按高光测并 −0.5~1EV，让暗部沉底 |
| 大树荫下全景 | 平均值偏暗 | +0.5EV 并留意主体受光方向 |
| 穿深色衣服占满画面 | 认为很暗 → 过曝 → 衣服发灰 | 对手背或灰卡测光代替 |

规律一句话：**画面里大面积的极端色调都要人工往回掰**。中央重点测光的机身还有个位置习惯——它偏信画面中心，所以"中心测光→锁定→重新构图"要练成固定动作序列。

## 测光、倒易律与弱光
### 测光策略与工具

- **机身测光可信吗**：八十年代后的电子单反基本可靠，但要先校验——对同一场景比对手机测光 App 与机身的建议值，偏差在一档内可放心用；
- **校验的具体流程**：找三个反差鲜明的场景（晴天街景、室内窗边、夜晚路灯下），手机 App 与机身各记一组建议值，偏差都朝同一个方向且超过一档，说明机身测光老化需要检修或整体补偿；
- **中央重点测光的习惯**：老机身多为中央重点，对人像就把人物脸部放在画面中心测光后锁定再构图；
- **点测光的进阶用法**：有点测的机身，对人像直接测脸颊高光位、对风光测中间调区域，比平均测光更稳；
- **什么时候才需要独立测光表**：玩全机械无测光机身且经常室内/夜景（阳光十六法管不到暗光）、或玩 120 双反时。新手阶段手机 App 就是最好的免费测光表。

### 倒易律失效

标称组合在极端快门下不再等效：理论上 f/8 + 1s 与 f/11 + 2s 等效，实际上长曝端会**进一步欠曝**。

| 快门区间 | 补偿建议 |
| --- | --- |
| 1/2000–1s | 基本无需补偿（现代乳剂表现良好） |
| 1–10s | 加 0.5–1 档（时间或开大光圈） |
| 10–100s | 加 1–2 档 |
| 更长 | 查该型号数据手册逐点补偿 |

黑白负片通常比彩负更耐长曝；具体曲线各卷不同，严肃夜拍前查官方 datasheet 是唯一正解。

### 夜景与弱光实拍参考

弱光是胶片的真正考场，给一组可直接套用的起点参数（均以 ISO 800 彩负、f/2 级定焦为前提）：

| 场景 | 起点组合 | 要点 |
| --- | --- | --- |
| 街灯下人像 | f/2 · 1/60s | 对脸部高光测光再收半档，保住肤色层次 |
| 霓虹街道氛围 | f/2.8 · 1/125s | 按高光霓虹测，让暗部沉下去出氛围 |
| 商场/餐厅室内 | f/2 · 1/60s | 白炽灯下色彩偏暖属正常，别开闪光破坏气氛 |
| 烛光/微光特写 | f/2 · 1/30s | 屏住呼吸贴支撑物，低于 1/30 就上脚架 |
| 城市夜景长曝 | f/8 · 数秒起 | 记得[倒易律失效](#倒易律失效)补偿，B 门配快门线 |

取舍原则一句话：**手持底线之内宁欠勿糊**——欠曝的彩负还能抢救一部分，糊掉的照片谁也救不了；真不够光就用更高 ISO 的卷或上脚架，不要硬撑慢门。

## 闪光、滤镜与自查
### 闪光灯与同步速度

胶片机用闪光的头号知识点是**闪光同步速度**：快门帘幕是两道缝扫过底片的，速度高于同步速度时底片只有一条缝被照亮——照片上出现一条黑色竖带。常见同步速度：F801 为 1/250s，多数老机械机在 1/60~1/125s。

实操口径：

- 手动闪光的基本公式：`光圈 = 闪光指数 GN ÷ 距离`（GN 见闪光灯铭牌，ISO 100 时）。距离 3m、GN 24 的灯 → f/8；
- 弱光下想压暗背景突出闪光主体：同步速度定住、光圈按闪光算，背景自然欠沉；
- 白天补光（fill-in）：比环境曝光**低 1~1.5 档**输出闪光，只提亮阴影不死板。

TTL 自动闪光当然更省心，但知道手动公式，你才能看懂 TTL 在做什么、错位时知道怪谁。

### 滤镜补偿与长曝

滤镜吃掉的光要在曝光里还回去：

| 滤镜 | 补偿量 | 说明 |
| --- | --- | --- |
| UV/保护镜 | ≈0 | 现代镀膜几乎无损 |
| CPL 偏振镜 | 约 −1⅔ ~ −2 档 | 消反光加深蓝天，人像暗光下慎用 |
| ND4 / ND8 | −2 / −3 档 | 白天长曝虚化流水必备 |

滤镜的光学原理与选型回链[附件](../器材/附件.md)，此处只记胶片侧的账。胶片特有的注意点：CPL 的补偿量随旋转角度变化，转好后要把最终角度的补偿计入；ND 长曝叠加[倒易律失效](#倒易律失效)，账要两层一起算——白天 f/16 + ND8 曝光 30s 起，实际可能需要 60~90s。

#### 参数记录习惯

每张记下：帧号、快门、光圈、特殊操作（补偿/迫冲/滤镜）。这不是仪式感——当第三卷出现整卷欠曝时，参数本是唯一能把"操作问题"和"机器问题"分开的证据。记录格式自由，一行一条即可：

```text
07  f/4  1/250  逆光人像 +1EV
08  f/16 1/125  海边顺光 CPL
```

关键是当场记，回家补记必漏。记录的价值在归因时兑现：整卷欠曝 + 参数本显示"全程没打补偿" → 操作问题；参数显示"该打的补偿都打了" → 机器或冲扫问题，直接进[故障诊断](常见故障诊断.md)的密度异常节。三卷之后你还会发现记录的副产品价值——它就是你的个人曝光数据库，哪类场景自己总偏差一目了然。

- [ ] 场景里有大面积白/黑？已做测光修正？

- [ ] 参数当场记录？
- [ ] 重要场景用了包围曝光（±1 各一张）？
