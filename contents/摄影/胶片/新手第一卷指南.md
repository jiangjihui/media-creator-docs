# 新手第一卷指南

> 本文是胶片组的**主线教程**：从"我什么都没有"到"在屏幕上看到自己拍的第一张胶片照片"，照着走即可。每个环节背后的展开知识走文中链接，不必先读完再动手。

## 出发前准备

> 信息核对时点：2026-08，二手行情波动大，以下为参考档位。

| 设备 | 建议 | 预算档 |
| --- | --- | --- |
| 机身 | 自动对焦胶片单反，测光+过片+对焦全自动，把学习焦点留给曝光本身：[尼康 F801](/contents/设备/单品档案/相机/NIKON-F801.md) 或[美能达 α7700i](/contents/设备/单品档案/相机/MINOLTA-a7700i.md) | 数百元 |
| 镜头 | 同卡口 50mm 标准定焦（视角接近人眼，练构图最诚实）或 28–80 级别套头 | 一两百元 |
| 胶卷 | 彩色负片 ISO 400 一卷（选型理由见下节） | 数十元 |
| 电池 | 按机型：F801 用 4×AA，α7700i 用 2CR5——测光和过片全靠它 | 十几元 |

合计 **500–1000 元即可开张**。不推荐新手第一台就上全机械机：没有自动过片、部分没有测光、快门全手动，三重难度叠加会淹没掉"拍照"这件事本身。

**为什么推荐 50mm 定焦起步**：它是同价位素质最好的选择（结构成熟、产量大、二手便宜），固定焦距还能逼你用脚构图——变焦环是新手构图的止痛药，按住它会推迟取景能力的形成。等你知道自己"总想更广"还是"总想更近"，再买第二支镜头，钱才花得准。

**二手单反开箱三查**（收货当天做，超期维权难）：

1. **快门各档听声**：从 1s 到 1/1000s 逐档空拍，高速档声音应干脆一致；迟滞、闷响、时快时慢都是帘幕老化的信号；
2. **测光反应**：装好电池半按快门，对明暗不同方向，取景器内曝光指示应明显移动；指示不动或乱跳直接退；
3. **过片与回卷**：装一卷废卷（或让卖家演示），听过片马达顺滑无卡顿、回卷到底无异响。

更完整的逐项验机表（含漏光测试、海绵状态）见两篇单品档案的[验机章节](/contents/设备/单品档案/相机/NIKON-F801.md)，选购思路对比见[胶片机身怎么选](胶片机身怎么选.md)。

如果单反的体积让你犹豫，三条替代路线也成立：口袋里的**傻瓜机**（百元级真香款见[机身怎么选](胶片机身怎么选.md)）、一卷 72 张的**半格机**（单张成本减半）、以及零学习成本的**一次性胶片机**——它们牺牲的是镜头素质与操控深度，换来的是随身率。


极简决策：**Gold 200 或 UltraMax 400 二选一**（柯达在产彩色负片，渠道足、价格低、宽容度高容错好）。光线以白天户外为主就选 ISO 200，想兼顾室内再选 400。完整选型逻辑（含反转片、黑白、电影卷）见[胶片种类与选择](胶片种类与选择.md)。

两个"第一卷别碰"：

- **反转片**：宽容度只有 ±0.5EV，第一卷大概率整卷翻车，且冲洗贵——留到第三、四卷再体验；
- **电影卷**：便宜大碗但走 ECN-2 工艺，remjet 除碳层有坑，详见[种类选择的电影卷专区](胶片种类与选择.md)。

购买渠道一句话：优先本地冲扫店和在产大厂官方渠道，电商平台认准店铺资质与生产日期——**问一句"哪年的卷"不丢人**，库存三年的卷和当年产的卷，灰雾水平不是一个档次（衰减规律见[过期节](胶片种类与选择.md)）。

## 拍摄执行

1. **避光环境操作**：室内即可，避免烈日直射下换卷；
2. **引片到位**：片头拉到收片轴标记位置、齿孔咬合齿轮后再关后盖——没咬合的典型症状是计数器不走、回卷手感为空（见[故障诊断](常见故障诊断.md)）；
3. **确认自动上片**：F801 / α7700i 关盖后自动过片到第 1 张，听马达声、看计数器走动；
4. **核对感光度**：有 DX 码识别的机身显示应与卷壳标称一致（400 卷显示 400）；老机身手动拨盘对准；
5. **检查电池**：电量低最先死的是测光——拍摄前半按快门看测光是否点亮。

**上片失败的现场处理**：关盖后计数器不走、过片声空转，不要反复开关后盖瞎试——开盖确认片头是否被拉过头（超过标记会被收片轴打滑）、齿孔有没有撕裂；引片舌撕裂就剪掉受损段重新引片，剪的时候避开齿孔区。两次尝试仍失败，换一卷别硬来，先排除是不是机身过片机构的问题（对照[卷片故障节](常见故障诊断.md)）。

装好卷后做个 30 秒快检：空按两次快门听声、轻晃机身无异响、后盖缝隙目视无翘曲。这三步能拦住大部分"整卷事故"，对应的翻车案例都收录在[故障诊断的全白全黑节](常见故障诊断.md)。


第一卷最忌讳"随手按完"。把它设计成一份作业，36 张花销才换得回经验：

| 段落 | 张数 | 练习设计 |
| --- | --- | --- |
| 曝光练习 | 第 1–12 张 | 固定一个场景，同一构图各拍 −1EV / 0 / +1EV 三档，共四组——建立"曝光差一档长什么样"的手感 |
| 题材练习 | 第 13–24 张 | 人像、街景、静物各 4 张：人像对脸部测光后锁定再构图；街景等光线；静物靠近用 f/5.6 以上景深兜底 |
| 自由创作 | 第 25–34 张 | 用前 24 张的经验自由发挥，每张按下前默念一遍曝光判断 |
| 应急保留 | 最后 2–3 张 | 不主动消耗，留给突发画面——这也是长期习惯 |

三个段落展开说：

- **曝光练习选什么场景**：要找**明暗混合但不极端**的场景——树荫下的街道、窗边的人像都合适。纯白墙或逆光大天空会把任何档位都拍成过曝，练不出对比。四组拍完别挪机位，回家对着扫描件横向比较：+1EV 那组阴影细节多了多少、高光糊到哪里，这比读十篇文章都直观；
- **题材练习的验收标准**：人像看脸是否曝光准确（背景可以烂）；街景看你是否等到了光线而不是到了就按；静物看边缘清晰度——这三条分别对应测光、耐心、景深三个基本功；
- **自由创作的纪律**：允许拍砸，但每张按下前必须能说出"我为什么用这个曝光"。说不出来就先站三十秒再按。第一卷的目标不是出片，是把"看—判—按"变成肌肉记忆。

**同步记录参数**：小本或手机备忘录记下帧号对应的快门/光圈/场景。这是日后归因问题的唯一证据链，习惯从第一卷养成，格式参考[曝光篇的记录节](曝光与拍摄逻辑.md)。记录模板不用复杂：`07 | f/4 | 1/125 | 傍晚街角 | −0.3EV` 一行足够。

## 后期与复盘

| 服务类型 | 内容 | 适用 |
| --- | --- | --- |
| 只冲不扫 | 仅显影出底片条带，单价最低但你拿不到电子图 | 打算自己翻拍的进阶玩家 |
| **冲扫一体（推荐）** | 显影 + 扫描出电子图，按分辨率分档 | 新手默认选择，选标准档即可 |
| 精扫/高清扫 | 高分辨率精细扫描，单价数倍 | 出片满意后的重点卷再回补 |

**分辨率档位怎么选**：店家通常分"基础 / 标准 / 高清"三档，对应大致 1–2M / 3–4M / 6M 级别的输出像素。**新手全程选标准档即可**——它的分辨率发社交媒体绰绰有余，且文件小、筛选快。真正值得精扫的是你筛出来的三五张满意之作：先用标准档全卷粗筛，再对重点底片回补精扫，比整卷精扫省一大截（数字化路线的完整对比见[扫描与翻拍篇](数字化扫描与翻拍.md)）。

下单注意：彩负选 **C-41 工艺**；勾选"按袋装不剪"可保留底片完整条带便于日后翻拍；邮寄用硬筒防压、避开弯折，包裹里附一张写有订单号的纸条——快递面单会磨掉，纸条不会。


1. **归档命名**：按 `日期_胶卷型号_序号` 建文件夹，原始扫描件与精修版分开存放；
2. **初筛**：先看整体密度与色调是否正常，把废片原因当场记下来；
3. **异常归因**：发现空白、发灰、漏光条带不要急着怪机器——对照[常见故障诊断](常见故障诊断.md)逐项定位，结论决定下次是换店、修机还是改操作；
4. **建"卷档案"**：给每一卷留一行记录——批次号、冲扫店家、服务档位、自己的主观评价（"偏黄""颗粒满意""第 20 张后全虚"）。三卷之后回看，你会清楚看到自己该在哪一环节升级，比凭感觉换设备靠谱得多。

**管理色彩预期**：胶片的颜色不是滤镜里的固定风格——同一张底片在不同店家、不同扫描设备、不同校正参数下颜色差异明显，甚至比机器之间的差异更大。第一卷拿到"和网上看到的 Gold 色不太一样"的结果完全正常，先排除技术性异常（对照诊断篇），再考虑换店家或学自己校正（见[数字化篇](数字化扫描与翻拍.md)）。

看到成片后，想继续深入哪个环节，回[胶片 · 总览](README.md)的链路总览挑下一站。


第一卷的价值在复盘，不在炫耀。动手做四件事：

1. **横向对比曝光练习那四组**，确定自己默认该偏向 + 还是 −（多数新手欠曝倾向明显，因为习惯性怕过曝）；
2. **统计废片类型**：虚焦多说明对焦锁定没做熟，欠曝多说明暗部判断保守，划痕多则要怀疑机身导轨或冲扫店；
3. **决定下一卷的方向**：换一个胶种体验色彩差异？还是同款卷专攻薄弱环节？一次只改一个变量，否则进步无法归因；
4. **校验设备短板是否真实存在**："想换机器"的冲动人人都有，但先用参数记录证明瓶颈在哪——是测光不准还是镜头受限，证据说话。

## 疑问与自查

**Q：第一卷用什么题材练最好？**
有明确主体的静态题材最划算：街角店面、家里静物、朋友半身像。大场面风光看着高级，但"哪里没拍好"很难归因；运动主体则把对焦难度叠加上来，留到第三卷以后。

**Q：一卷拖多久拍完合适？**
建议 **2–4 周内**收尾。拖太久有两个代价：批次记忆模糊（第几帧拍的什么想不起来，参数记录失效）、以及卷在机身里暴露更久（夏季高温是胶卷杀手）。反过来也别为赶进度乱按——每一张都要有按下快门的理由。

**Q：拍到一半相机没电了怎么办？**
直接换电池即可，**不要开盖**——已拍部分安全待在暗盒里。换完电注意两件事：部分老机型计数器和 ISO 设置会归零需重设；如果换电时误触了回卷钮，先确认回卷状态再继续拍（叠帧与空白帧的排查见[故障诊断](常见故障诊断.md)）。长期存放前把电池取出，漏液是老机身头号杀手。

**Q：需要买独立测光表吗？**
不需要。手机测光 App + 机身自带测光互相校验，覆盖新手期全部场景；阳光十六法作为无电估光兜底，见[曝光与拍摄逻辑](曝光与拍摄逻辑.md)。测光表是玩全机械无测光机身之后才值得上的工具。

**Q：扫描件颜色怪，是我的机器坏了吗？**
大概率不是。彩负扫描要经过反色与去色罩校正，颜色受店家风格影响极大——先用[故障诊断](常见故障诊断.md)排除密度异常等技术问题，再判断是否只是审美差异。

**Q：用过期卷练手可以吗？**
可以且省钱：过期卷按降一档感光度用、选顺光明亮场景兜底即可，衰减规律与保存纪律见[种类选择的过期节](胶片种类与选择.md)。但重要场合别用它——容错率确实更低。


- [ ] 机身测光工作正常（电池已查，二手开箱三查通过）？
- [ ] 装卷后计数器走动、过片声正常？
- [ ] ISO 显示与胶卷标称一致？
- [ ] 前 12 张按 ±1EV 分档执行并记录了参数？
- [ ] 全卷拍完后立即回卷再开后盖？
- [ ] 送冲选择了 C-41 工艺 + 冲扫一体（标准档）？
- [ ] 底片条带已保留、扫描件已按规则归档？
- [ ] 参数本已建立并坚持当场记录？
- [ ] "卷档案"已建档（批次/店家/主观评价）？
- [ ] 异常画面的原因已在诊断篇里找到归属？
