> 新手建议：**人像 → 风光 → 街拍 → 产品静物**（从"最容易上手"到"最吃布光功力"）。也可以按你实际要拍的题材直接跳读——每篇都自洽，引用前面基础文章的链接都在文末「延伸」。

- 人像：重沟通与引导，建议配合 [人像精修](../后期处理/人像精修.md) 阅读。
- 风光：重时机与等待，建议配合 [用光](../拍摄技术/用光.md)、[Lightroom 工作流](../后期处理/Lightroom工作流.md) 阅读。
- 街拍：重观察与预判，建议配合 [构图](../拍摄技术/构图.md)、[对焦与景深](../拍摄技术/对焦与景深.md) 阅读。
- 产品静物：重布光与摆放，建议配合 [用光](../拍摄技术/用光.md)、[修图基础](../后期处理/修图基础.md) 阅读。
