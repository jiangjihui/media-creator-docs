# 器材 · 总览

> 器材是「你能不能把想法落到画面」的物质基础。本组文章不堆型号参数（那会过时），而是讲清**每个器材背后的 trade-off**：机身你换得勤、镜头能用十年、附件决定你能否稳定输出。选购时按「系统 > 镜头 > 机身 > 附件」的优先级思考。

| 文章 | 核心问题 | 关键工具 |
| --- | --- | --- |
| [相机机身](相机机身.md) | 选什么系统、画幅/对焦/卡口怎么定 | 画幅、对焦、卡口、续航 |
| [镜头](镜头.md) | 焦距/光圈/素质决定拍什么、拍多好 | 焦距、最大光圈、画质 |
| [附件](附件.md) | 能否稳定把照片输出出来 | 三脚架、存储卡、滤镜 |
| [曝光三要素](曝光三要素.md) | 亮度由谁决定、各自附带什么副作用 | 光圈 / 快门 / ISO 的 trade-off |

> 阅读建议：先从曝光三要素打底（它决定你拍的每一张亮不亮、糊不糊、噪不噪），再去挑机身和镜头；附件按实际痛点补，别被消费主义带节奏。
