# 拍摄技术 · 总览

> 拍摄技术是"前期可控的所有手段"的集合：构图、用光、对焦与景深。本组文章按"读图 → 决定怎么拍 → 落实参数"的顺序串起。

| 文章 | 核心问题 | 关键工具 |
| --- | --- | --- |
| [构图](构图.md) | 观者的注意力放在哪 | 减法、引导线、留白、视角 |
| [用光](用光.md) | 光从哪里来、什么质感、什么颜色 | 光位、软硬、色温、光比 |
| [对焦与景深](对焦与景深.md) | 哪里清楚、清楚多少 | 对焦模式、光圈、焦距、距离、传感器 |

> 阅读建议：先构图（决定讲什么）→ 用光（决定情绪）→ 对焦与景深（决定信息密度）。三件套决定一张照片的"内容"，曝光三要素决定"亮度"。
