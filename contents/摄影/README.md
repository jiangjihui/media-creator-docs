# 摄影 · 总览

> 摄影的本质是「用光作画 + 把瞬间定格」。本手册的摄影部分按「**器材 → 拍摄技术 → 后期处理 → 题材实战**」的顺序组织：先把工具认识清楚，再学前期怎么拍，然后学后期怎么修，最后落到具体题材该怎么上手。
> 另有「**胶片**」分组作为一条平行工作流（选机选卷 → 拍摄 → 冲洗 → 数字化），零基础从[新手第一卷指南](胶片/新手第一卷指南.md)进。
> 每一篇都尽量做到「先讲清原理，再给可执行的做法」，少抄参数、多讲 trade-off——因为参数会过时，判断力不会。

## 建议学习顺序

> 新手建议：**器材**（至少读完「曝光三要素」）→ **拍摄技术**（构图 → 用光 → 对焦与景深）→ **后期处理**（修图基础 → Lightroom 工作流）。人像精修可作为后期的人像专项补充，在前面打牢后按需看。
> 题材实战不急着读——它是「把前面所有知识综合到某个场景」的实战篇，前面越扎实，这里越通透。
