# 方法论 · 总览

> 方法论，是把「摄影 / 摄像 / 自媒体」三个板块共通的心法单独抽出来的一层。它们不绑定某个形态，而是跨形态通用的底层能力：怎么讲故事、怎么用色彩、怎么定选题。本文属于 [自媒体运营 · 总览](contents/自媒体运营/README.md)。

## 定位与关系
### 方法论单列

摄影教你怎么拍好一张图，摄像教你怎么拍好一段视频，自媒体教你怎么运营一个号——但它们的「底层」是同一套：好内容都要有叙事、有情绪、有结构。把这些通用心法抽出来，避免三个板块各写一遍，也方便你横向打通。

| 板块 | 用到的方法论 |
| --- | --- |
| 摄影 | 色彩理论（后期）、故事叙事（组图） |
| 摄像 | 故事叙事（剪辑）、色彩理论（调色）、选题框架 |
| 自媒体 | 三者全用 |

### 三篇定位与关系

| 文章 | 解决什么 | 下游落点 |
| --- | --- | --- |
| [故事叙事](contents/自媒体运营/方法论/故事叙事.md) | 内容怎么被记住 | 剪辑、文案 |
| [色彩理论](contents/自媒体运营/方法论/色彩理论.md) | 画面怎么有情绪 | 调色、封面 |
| [选题框架](contents/自媒体运营/方法论/选题框架.md) | 今天发什么 | 内容策划、选题库 |

三者关系：选题框架定「做什么」→ 故事叙事定「怎么讲」→ 色彩理论定「长什么样」。顺序可循环——讲清楚了再想画面，或先有画面再补叙事，都行。

### 与摄影摄像交叉

- 色彩理论 ↔ [摄影 · 后期处理](contents/摄影/后期处理) 与 [摄像 · 影视制作 · 剪辑与调色](contents/摄像/影视制作/剪辑与调色.md)：前者讲原理，后者讲操作。
- 故事叙事 ↔ [摄像 · 影视制作](contents/摄像/影视制作/README.md)：前者讲结构，后者讲拍摄执行。
- 选题框架 ↔ 所有板块的「拍什么」。

## 怎么用
### 怎么用这一层

不要孤立读方法论。读 [故事叙事](contents/自媒体运营/方法论/故事叙事.md) 时，同时看 [摄像 · 剪辑](contents/摄像/影视制作/剪辑与调色.md) 怎么落地；读 [色彩理论](contents/自媒体运营/方法论/色彩理论.md) 时，看 [摄影 · 后期](contents/摄影/后期处理) 怎么调。原理 + 操作，才完整。

### 学习顺序

新手不必三篇齐学，按顺序来：

| 顺序 | 先学 | 理由 |
| --- | --- | --- |
| 1 | [选题框架](contents/自媒体运营/方法论/选题框架.md) | 最落地，每天用得到 |
| 2 | [故事叙事](contents/自媒体运营/方法论/故事叙事.md) | 让内容立得住 |
| 3 | [色彩理论](contents/自媒体运营/方法论/色彩理论.md) | 锦上添花，后期再精 |

先把「发什么、怎么讲」搞定，色彩是最后一公里。

### 读后判断

三篇方法论读完后，你不一定能立刻写出神作，但应该建立起几个「自动化判断」。看到一条爆款，你会本能拆它的叙事结构（钩子在哪、情绪曲线怎么走），而不是只觉得「好厉害」。看到一张好图，你会下意识吸它的主色、判断冷暖调性，而不是只觉得「好看」。接到一个选题，你会先问「这算痛点还是盲区、值得做几篇」，而不是凭手感接。这三个判断，就是方法论内化成直觉的标志——你开始用「框架」代替「感觉」。判断不是终点，要落到动作：每周挑一条你欣赏的内容，用三件套各拆一遍，记一句「它好在哪、我下次怎么用」。坚持一个月，你的审美和拆解速度会明显提升。方法论的价值从来不在「知道」，在「用得上的判断」——这也是它和 [内容策划](contents/自媒体运营/内容策划.md)、[平台策略](contents/自媒体运营/平台策略.md) 这类操作文最不同的地方：它改的是你的底层，不是你的步骤。

## 映射与复用
### 形态映射表

| 方法论 | 摄影 | 摄像 | 自媒体 |
| --- | --- | --- | --- |
| 故事叙事 | 组图叙事 | 剪辑节奏 | 文案/脚本 |
| 色彩理论 | 后期调色 | 调色 | 封面/品牌色 |
| 选题框架 | 拍什么 | 拍什么 | 发什么 |

横向看，三篇方法论像「胶水」，把摄影/摄像/自媒体三个生产侧粘成一个体系。读操作文章时，回来对照这一层，理解会深一层。

### 复用场景举例

举几个具体场景，看方法论怎么落地。你拍了一组美食图（摄影侧），用 [色彩理论](contents/自媒体运营/方法论/色彩理论.md) 定调性、用 [故事叙事](contents/自媒体运营/方法论/故事叙事.md) 排组图顺序，让九张图有起承转合而不是随便堆。你剪了一条 Vlog（摄像侧），用 [故事叙事](contents/自媒体运营/方法论/故事叙事.md) 定结构（钩子在前 3 秒、中段有转折）、用 [选题框架](contents/自媒体运营/方法论/选题框架.md) 定标题，让内容被看见。你写公众号（自媒体侧），用 [选题框架](contents/自媒体运营/方法论/选题框架.md) 定选题、用 [故事叙事](contents/自媒体运营/方法论/故事叙事.md) 写开头，让读者读下去。你会发现：生产侧每出一件作品，都回来方法论工具箱挑一件用——它不是独立知识，是粘在摄影/摄像/自媒体上的那层「为什么好」。久而久之，你做内容不再是凭手感，而是有意识地在用叙事、色彩、选题三件套。

### 误用提醒

方法论也会被误用。一是「只学不练」：三篇读得滚瓜烂熟，做内容时全忘，等于没学。正确做法是每读一篇，立刻在你账号上落一条动作。二是「生搬硬套」：把故事叙事的模板当公式填，丢了真实素材，内容变假。方法论是「思考框架」不是「填空题」，填的是你的真东西。三是「过度方法论」：每条都先画情绪曲线、配色方案，生产慢三倍，反而断更。方法论是底层习惯，熟了就长在直觉里，不必每条显式走一遍。四是「孤立使用」：只读方法论不回摄影/摄像操作文，懂原理不会落地。原理加操作，才完整——这一点 [影视制作 · 剪辑与调色](contents/摄像/影视制作/剪辑与调色.md) 和 [摄影 · 后期处理](contents/摄影/后期处理) 是最好搭档。
