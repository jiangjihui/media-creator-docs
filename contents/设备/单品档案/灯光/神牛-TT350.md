# 神牛 TT350 机顶闪光灯

> **定位**：神牛（Godox）TT350 是入门 / 进阶皆宜的**机顶热靴 TTL 闪光灯（speedlite）**，主打小、轻、便宜、功能完整——GN36、24–105mm 自动变焦、TTL + 手动 + 频闪、1/8000s HSS、神牛 X 2.4G 无线主控 / 从属。它吃相机热靴供电（2× AA），是 AD200 一类外拍灯之外的"随身补光第一盏"。**关键点：TT350 按相机品牌分型号**（TT350C / N / S / F / O 对应佳能 / 尼康 / 索尼 / 富士 / 奥巴松下），买错卡口版本 TTL 用不了。客观参数如下，个人体验见「使用体验速记」。

## 定位与适用场景

### 定位与产品线坐标

TT350 在神牛 speedlite 家族里处在"最小巧全能"档：比自家的 TT685 / V860 III 小一圈、轻一半、便宜不少，但 TTL、HSS、无线全保留；比玩具级小灯（如神牛 iM 系列）多了 24–105mm 变焦与完整神牛 X 无线主控能力。直接对手是佳能 430EX、尼康 SB-500、索尼 HVL-F28RM 等原厂小灯——TT350 用约三分之一原厂价给到接近甚至更全的功能，是"副厂性价比补光第一盏"的典型。

它和本站已收录的 AD200 是**两类东西**：AD200 是离机便携外拍灯（200Ws、自带电池、可换灯头、品牌无关），TT350 是**插在相机热靴上、由相机供电的机顶灯**，靠 2× AA 出光、GN 仅 36。两者常组合使用——TT350 上机顶打眼神光 / 直补，AD200 做离机主光。

### 操控与安装方式

- **热靴安装**：直接插相机热靴，按相机品牌选对应版本（C/N/S/F/O），锁扣固定；TTL 与高速同步由相机协议自动协商，装好即用。
- **机身操控**：小屏 + 四个方向键 + 拨轮，功率 / 模式 / 组别 / 频道直调；机身体积小，单手盲操需熟悉按键位置。
- **2.4G 无线**：内置神牛 X 接收，**可作为主控引闪其他神牛灯（如 AD200 / TT685）**，也可作从属被 X2 / X3 / XPro 发射控。3 组（A/B/C）× 16 频道，最远约 30m，适合"机顶 TT350 引闪离机 AD200"的轻量双灯布光。
- **灯头活动**：俯仰 -7° 到 +90°、水平旋转 270°，可跳闪打天花 / 墙面柔化；广角散光片下拉到约 15mm 覆盖超广角镜头。

## 光质与性能

### 输出与回电

GN36（@105mm）属小灯正常水平——近距离人像、室内补光、跳闪足够，但压大白天户外环境光就吃力（这正是 AD200 这类外拍灯的用武之地）。回电 0.1–2.2s，低功率几乎无感；满电约 210 次全光闪，一组镍氢走完大半场活动拍摄没问题。2× AA 供电意味着随时能换电池续命，不像内置锂电灯"没电就得充"。

### 色温与显色

标称 5600K ±200K（日光平衡），TTL 自动白平衡下肤色与物体色彩一致性友好；作为补光主力时建议相机白平衡锁定或手动 5600K，多灯 / 多张同场景不偏色。注意它**没有 AD200 Pro 那类"稳定色温模式"**，功率大幅变化时色温会有 ±200K 区间漂移，棚拍精校色温场景要心里有数。

### 同步与高速闪光

支持 **1/8000s HSS**，大白天开大光圈压环境、定格运动可用；前 / 后帘同步可选，后帘适合夜景车流 / 光绘拖尾；MULTI 频闪（90 次 / 99Hz）可玩水滴、舞者创意定格。作为机顶灯，这些同步能力靠相机热靴协议传递，原厂协议支持度随机型与固件版本而异，买前确认你的机身是否在神牛兼容列表。

### 变焦与造型光

- **灯头变焦 24–105mm**：自动跟随镜头焦距（相机传焦距给灯），也可手动锁焦距；长焦端 GN 更高、光束更聚，广角端铺光更宽。这是它比固定头小灯实用的一大处。
- **广角散光片**：下拉覆盖约 15mm，配超广角镜头不出现暗角。
- **造型光 / 对焦辅助**：无独立建模灯，但带红外 AF 辅助灯，暗光下帮相机合焦；试拍前可短按试闪确认出光。

## 供电与配件生态

### 电池续航与充电

吃 2× AA——**推荐镍氢（Ni-MH，如 eneloop）**，比碱性电池回电快、循环成本低；碱性也能用但回电慢、易漏液。满电约 210 次全光闪；**待机 90s 自动关机**省电（半按快门 / 按灯上键唤醒）。无内置锂电、无 USB 充电，续航靠备一组电池解决，正因如此它比锂电灯更"随时能复活"。

### 控光附件与卡口

- **热靴即卡口**：插相机热靴即用，无需额外支架；离机时用神牛 X 无线或 PC 同步线 / 3.5mm 引闪。
- **灯头附件**：机顶灯灯头较小，柔光件多为小巧款——柔光片（贴灯头）、小型跳闪罩、蜂巢（需转接环）；想上大柔光箱得靠离机灯（AD200 一类）而非它。
- **无线生态**：作为神牛 X 主控可引闪 AD200 / TT685 / V 系列，组轻量双灯 / 多灯；配件预算低，是它"生态入口"价值所在。

## 选购与验机

### 优缺点与适用人群

- **优点**：小巧轻便（约 200g、比手机大一点）、便宜、TTL + HSS 到 1/8000s 齐全、24–105mm 变焦实用、神牛 X 无线可主控可当从属、AA 供电随时换电、五品牌版本覆盖主流机身。
- **缺点**：GN36 压大环境光弱（户外硬光吃力）；无稳定色温模式（功率变化色温漂移 ±200K）；仅 3 组无线（A/B/C，少于 AD200 的 16 组）；小屏 + 紧凑按键盲操需练；无内置锂电 / USB 充电。
- **适合**：入门学闪光灯、活动 / 婚礼跟拍随身补光、Vlog 跳闪柔化、已有神牛 X 体系想添一盏机顶主控灯的用户。
- **不适合**：大白天户外压光主力（看 AD200 / AD400）、需要 4+ 组精细多灯布光、追求原厂灯与机身深度联动（如索尼原厂离机协议）的严谨用户。

### 验机与避坑

| 验机项 | 检查要点 |
| --- | --- |
| 1. 版本匹配 | 确认买的是对应机身版本（C/N/S/F/O），错版 TTL / HSS 不可用 |
| 2. TTL | 上机自动曝光是否正常，正负补偿生效 |
| 3. HSS | 开 1/8000s 高速同步是否过曝可控 |
| 4. 变焦 | 自动跟随镜头焦距变化、手动锁焦距有效 |
| 5. 无线 | 作从属被 X 发射控、作主控引闪 AD200 各测通 |
| 6. 回电与续航 | 满电全光闪是否接近 210 次；镍氢回电是否 ≤2.2s |
| 7. 固件 | micro-USB 连电脑升级到最新，修 TTL 兼容性 |

## 使用体验与自查

### 使用体验速记

- 体积：约 200g、比手机大一圈，挂机上几乎不觉重，是它最常被带出门的原因——比 AD200 轻一个量级。
- 跳闪：俯仰 + 旋转够打天花 / 墙面，室内人像跳闪比直打柔太多，新手也能快速出片。
- 续航：一组镍氢走完大半场活动，备一组轮换无焦虑；自动关机 90s 省电但连拍间隙别让它睡死。
- 生态：作主控引闪离机 AD200 很顺，"机顶 TT350 + 离机 AD200"是轻量双灯经典组合。
- 短板：GN36 压大白天户外吃力，遇到硬光环境得升功率 / 升灯；小屏按键紧凑，盲操要练。

### 自查与常见误区

- **误区一：买错版本**。TT350C/N/S/F/O 对应不同品牌热靴协议，错版 TTL / HSS 直接失效——下单前核对机身。
- **误区二：当外拍压光主力**。GN36 压大白天户外环境光弱，硬光需求看 AD200 / AD400 一类外拍灯。
- **误区三：忽视色温漂移**。无稳定色温模式，功率大幅变化时 ±200K 漂移，精校色温场景手动锁白平衡。
- **误区四：碱性电池凑合**。碱性回电慢、久放易漏液，长期用推荐镍氢（eneloop 类）。
- **自查清单**：确认版本匹配 → 上机试 TTL → 开 HSS 测压光 → 变焦跟随镜焦 → 无线主控 / 从属配对 → 备一组镍氢 → 固件升最新。
