## 定位与适用场景

### 定位与产品线坐标

Q120 处在「speedlight 机顶闪」与「AD200/AD300 一类集成小灯」之间的便携外拍档：120Ws 比机顶闪有明显压环境余量，又比大功率 monolight 轻、便宜。直接对手是神牛 AD100 Pro（Fstoppers 评测称 Q120 约其半价）、各品牌 100–150Ws 便携灯。圆头设计兼容磁吸柔光配件，体积小到能塞进相机包镜头格。

### 操控与引闪方式

- **本体操控**：机身按键调功率 / 模式 / 组别 / 通道，另支持蓝牙 App 遥控，单人外拍布光不用来回跑。
- **2.4G 引闪**：需配 QZ/QPro 触发器（不随机），最远 100m、5 组 32 通道。
- **最大亮点——兼容 Godox X 系统**：开 RX COMP 菜单后，用神牛 Xpro / X3 / X2 发射即可直接控，已有神牛体系的用户几乎零成本接入；也支持 S1/S2 光引闪与 2.5mm 同步口兜底。

## 光质与性能

### 输出与回电

120Ws、1/256–1/1 共九档；回电 0.01–1.5s（低功率几乎无感，满光 ≤1.5s）；满电 410–420 次全光闪，一天外拍基本够用；内置散热系统支持连续全光闪，不会轻易过热保护。

### 色温与显色

5600K ±100K 日光平衡，TTL 自动曝光下肤色与物体色彩一致性友好；多张同功率不偏色是它比廉价灯更稳的地方。

### 同步与高速闪光

配 QZ/QPro 触发器支持 **1/8000s HSS**，大白天也能开大光圈压环境、定格运动；前 / 后帘同步可选；MULTI 频闪（最高 100Hz、100 次）适合拍水滴、舞者等创意定格。

### 变焦与造型光

内置 28–105mm 可调变焦控制光束覆盖（圆头），远打收束、近打铺开；3W 造型光 1–10 级，暗光下构图与对焦好用，只是 3W 偏弱，精细布光别指望它。

## 供电与配件生态

### 电池续航与充电

7.2V / 3000mAh 锂电，满电 410–420 次全光闪；**USB-C 充电**（广泛兼容充电宝，外拍可边充边续），这是比很多老灯方便的地方。整机含电池 671g，单手可持、配金属手柄手持打光也稳。

### 控光附件与卡口

圆头磁吸，附**磁吸柔光罩**（diffusion dome 直接吸合）；保荣卡口需另购 CRB1 S 支架转接；标配金属手柄 + 收纳包；底部 1/4″ 螺孔接灯架。想玩柔光箱 / 雷达罩的，记得把保荣转接算进预算。

## 选购与验机

### 优缺点与适用人群

- **优点**：120Ws 压环境有余、671g 轻、TTL + HSS、回电快、410–420 闪续航、圆头磁吸配件、兼容 Godox X 生态、价格低（约神牛 AD100 Pro 半价）、USB-C 充电。
- **缺点**：HSS 需另购 QZ/QPro 触发器（不随机）；LCD 强光下难读；固件升级对新手不友好；仅 120Ws，硬刚正午烈日 + 大柔光箱仍吃力；造型光仅 3W 偏弱。
- **适合**：户外人像、产品小件、婚礼细节、创作者外拍，以及**已有神牛 X 体系、想加一盏便宜便携灯**的用户。
- **不适合**：需要 200Ws+ 压大场景、棚拍主光、要强造型光的场合。

### 验机与避坑

| 验机项 | 检查要点 |
| --- | --- |
| 1. 输出与回电 | 满光输出是否达标，回电是否 ≤1.5s |
| 2. TTL | 在尼康 / 佳能 / 索尼机身上自动曝光是否正常 |
| 3. 引闪配对 | 配 QZ/QPro 或神牛 X 发射，测 100m 内稳定性 |
| 4. Godox 兼容 | 确认 RX COMP 菜单已开，X 发射能控 |
| 5. 电池 | 满电全光闪是否接近 410+ 次 |
| 6. 配件 | 磁吸柔光罩吸合、USB-C 充电、1/4″ 螺孔与灯架配合、色温多张不偏 |

## 使用体验与自查

### 使用体验速记

> 以下为通用长期使用观察代拟，待你按真实体验校订。

- 体积：约一支 24-70 镜头大小，塞相机包镜头格即可，随身无负担，是它最容易被带出门的原因。
- 重量：671g 单手可持，金属手柄手持补光也稳，单兵作战友好。
- 回电：1/2 功率拍人像基本不卡，连续拍无压力；低于满光几乎边拍边回。
- 兼容：已有神牛 X 发射的用户最爽——开 RX COMP 直接接管，不用再买钮尔触发器。
- 短板：HSS 要另买 QZ/QPro；强光下屏难读，户外调参凭手感；3W 造型光偏弱，暗光构图靠它勉强。

### 自查与常见误区

- **误区一：以为自带 HSS**。需配 QZ/QPro 触发器且走 2.4G 无线模式才上 1/8000s，光引闪 / 同步口不触发 HSS。
- **误区二：当棚拍主光**。120Ws 压不住大场景硬光，大柔光箱远打吃力，别指望替代 200Ws+ 灯。
- **误区三：忽视 Godox 兼容**。已有神牛体系记得开 RX COMP，免得又花一份触发器钱。
- **自查清单**：出门前满电 → 试 TTL → 引闪配对（或开 RX COMP）→ 备柔光罩 / 手柄 → 带 USB-C 线续命。
