## 定位与适用场景

### 定位与产品线坐标

YN LUX 100 卡在"便携双色温 COB 灯"甜区：100W、双色温 3200–5600K、CRI≥95，Bowens S 卡口直接吃主流柔光箱 / 标准罩，还能装 NP-F / V-mount 电池手持外拍。对手是神牛 SL-100W、爱图仕 / 永诺 YNRAY 系列等。它赢在双色温 + 电池便携 + 风扇可关（静音），代价是功率低于 150W 灯（影器 GC150）、无反光伞接口、配件（电池 / 适配器）多需另购。

### 操控与安装方式

- **操控**：机身旋钮无级调光 + LCD 读数；蓝牙连 Yongnuo App（安卓 / iOS）远程调光 / 开关 / 特效，离机布光不用来回跑。
- **安装**：1/4″-20 螺孔上灯架 / 怪手；附手持手柄支架，可装入 2× NP-F 或 1× V-mount 电池变手持补光。注意**无反光伞接口**（Umbrella Mount: No），想用伞得走保荣卡口转接。
- **卡口**：Bowens S（保荣）口，标准罩 / 柔光箱 / 雷达罩 / 束光筒即插即用。

## 光质与性能

### 亮度与显色

100W COB 输出约 11,326 lux @ 1m（5600K，配 55° 反光罩），双色温 3200–5600K 连续可调，CRI ≥ 95 显色比 YN100 太阳灯（CRI≥90）更准，日常 / 电商 / 访谈够用；无级调光配合保荣附件控光。和影器 GC150（双色温 150W）相比功率低一档，但体积小、能手持电池供电。

### 散热与持续输出

100W 持续常亮，靠**风扇主动散热**（标称噪声 <25dB，且**可手动关闭**——这是它比 YN100 太阳灯友好的地方，静音访谈 / ASMR 可关扇）。满功率恒温运行，长时间不降亮；Enhanced / Standard 两档功率（100W / 60W）按需切换省电。

## 供电与配件生态

### 供电与续航

**双供电**是它最大的便携卖点：插 **AC 适配器**（DC 19V 5A，多数套装随附）即满功率 100W；没电时装 **2× NP-F 或 1× V-mount 电池**（装入手柄支架，均另购）手持外拍，Enhanced 60W / Standard 30W 续航更久。和纯 AC 的 YN100 太阳灯、甚至和内置电池的影器 GC150 都不同——它靠通用 NP-F / V-mount 生态，电池可和相机 / 监视器通用。

### 控光附件与卡口

Bowens S（保荣）口是核心：标配 55° 反光罩，标准罩 / 柔光箱 / 雷达罩 / 束光筒即插即用。注意：**无反光伞接口**，用伞需保荣转接；NP-F / V-mount 电池、AC 适配器多数需另购，出门前把电池 / 适配器 / 控光件一起打包。

## 选购与验机

### 优缺点与适用人群

- **优点**：100W 双色温（3200–5600K）、CRI≥95、可 AC 可电池手持、风扇可关（静音）、Bowens 生态、App 遥控、体积小（12cm 立方）、比纯 AC 灯便携。
- **缺点**：功率低于 150W 灯压大场景吃力；无反光伞接口；电池 / 适配器多需另购；标配多为白光版，要 RGB 得选对应 SKU。
- **适合**：视频 / 直播补光、静物小件、电商拍摄、单兵外拍、新手布光练习。
- **不适合**：需要 >150W 压大场景、必须用反光伞（无伞口）、对显色 ≥97 影视级需求。

### 验机与避坑

| 验机项 | 检查要点 |
| --- | --- |
| 1. 调光线性 | 无级调光是否平滑、有无频闪 |
| 2. 色温 | 3200–5600K 两端及中间档，用白纸 / 色度计对比偏差 |
| 3. 显色 | CRI 是否 ≥95（标称），实拍肤色 / 物体色准 |
| 4. 风扇 | 噪声是否 <25dB，关机功能是否正常 |
| 5. 电池 | NP-F / V-mount 装入手柄是否锁附、Enhanced/Standard 功率是否符合 |
| 6. 卡口 | Bowens S 锁附牢固，反光罩 / 柔光箱吸合；确认无伞口 |
| 7. 无线 | App 蓝牙配对（256 频道），调光 / 开关 / 特效正常 |

## 使用体验与自查

### 使用体验速记

- 手持：约 700g 灯体 + 手柄装 NP-F 单手可持，12cm 立方小巧，外拍塞包无负担；比影器 GC150（1.14kg）轻。
- 光质：双色温 + CRI≥95 混光自由，配保荣柔光箱铺光柔和，视频 / 静物出片稳；比 YN100 太阳灯（单色温 CRI90）显色更准。
- 静音：风扇可关是亮点，访谈 / ASMR 关扇即静音，但关扇后长时间满功率注意温控。
- 供电：AC / NP-F / V-mount 三选一最灵活，电池和相机通用是加分；缺点是电池 / 适配器多需另购，首购要把账算全。
- 槽点：无反光伞接口，习惯用伞的要转接；100W 压大场景弱于 150W 灯。

### 自查与常见误区

- **误区一：当闪光灯用**。YN LUX 100 是常亮灯（持续光，规格表 Built-In Flash: No），不是 TTL 闪光灯，不能 HSS / 压环境曝光，别和 AD200 一类混淆。
- **误区二：以为随机带电池 / 适配器**。AC 适配器部分套装随附、电池（NP-F / V-mount）均另购，首购先确认包装。
- **误区三：以为能插反光伞**。无伞口（Umbrella Mount: No），用伞走保荣转接。
- **误区四：忽视风扇可关**。静音场景记得关扇，但关扇满功率别久烤。
- **自查清单**：出门前带 AC 适配器 / NP-F·V-mount 电池 → 带保荣控光件 → 试双色温偏差 → 风扇开关确认 → App 蓝牙配对。
