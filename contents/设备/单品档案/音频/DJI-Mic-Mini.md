## 定位与操控

### 定位与产品线坐标

DJI Mic Mini 是 DJI Mic 系列里的「轻量入门款」，与同门旗舰 **DJI Mic 2** 形成清晰分工：

| 维度 | DJI Mic Mini | DJI Mic 2 |
| --- | --- | --- |
| 发射器重量 | 约 10g | 约 28g |
| 传输距离 | 400m | 约 250m（FCC）/ 160m（CE） |
| 机身内录 | **不支持** | 8GB、32-bit float 内录 |
| 降噪 | 两档主动降噪（强 / 弱） | 智能降噪 |
| 操作 | 拨盘 + 按键 | 触屏 + 拨盘 |
| 两发一收含盒定价 | ¥999 | 明显更高 |

横向看，它在「10g 级超轻」这条线上对标猛犸 Lark M2、罗德 Wireless GO II 的轻量思路，但靠大疆生态（OsmoAudio 直连、DJI Neo 联动）和 ¥999 的定价把「无感佩戴 + 低门槛」做到位。一句话定位：**给手机 / Osmo 用户的第一支无线麦，而非给棚拍与高可靠采集的旗舰**。

### 佩戴与连接操控

- **10g 无感佩戴**：磁吸片 + 夹持两种戴法，薄面料上也不外翻；发射器本体即是麦克风，无外接领夹线。
- **开盖即连**：发射器入盒自动关、出盒自动开机配对；接收器插上相机 / 手机即识别。
- **物理操作极简**：发射器上一颗拨盘 + 按键，负责开关、降噪档位、低切、录音指示；没有触屏，盲操友好。
- **一体收纳**：充电盒可同纳 2 发射器 + 1 接收器 + 转接头 + 防风毛套（毛套不用取下即可入盒），转场省心。
- **多设备兼容**：相机走 3.5mm TRS（与相机同步开关机）；手机可蓝牙直连免接收器，也支持免插拔外放、用手机电量反向充电；Osmo 生态经 OsmoAudio 直连，音质更通透且省去接收器。

## 收音与性能

### 音质与降噪

- **全指向 + 120dB SPL**：全指向意味着不挑朝向、走动不丢声；120dB 上限足够应对近距离人声与稍大声压场景，不易爆。
- **两档主动降噪**：弱档适合室内较安静环境、尽量少损人声；强档适配户外嘈杂，大幅压环境噪声且保持通透。配合**自动限幅**，音量过高时自动压低避免爆音——对口播、直播这类难补录的场景很实用。
- **安全音轨**：同步录一条 -6dB 备份轨，主轨万一瞬间过载，后期还有保底。
- **低切开关**：开低切切到 100Hz 起，能有效压掉风噪、空调底噪等低频隆隆声。
- 注：官方参数页未标注采样率 / 位深，实测为高清数字传输；等效噪声 24 dBA 属清干净的底噪水平。

### 传输与抗干扰

- **400m 标称传输**：2.4G 频段 GFSK 2Mbps，城市人流 / 车流等复杂电磁环境下实测稳定，日常拍摄距离（几米到十几米）几乎无感。
- **蓝牙 5.3 直连手机**：不用接收器也能手机直播、用第三方 App 拍摄收音，是它相比多数竞品的独特便利。
- 短板提醒：2.4G 在密集 WiFi / 蓝牙环境可能受挤，远距离或有厚墙遮挡时偶有抖动，重要场地建议走有线兜底（见下）。

### 备份与短板（无内录）

- **最核心取舍：不支持机身内录**。DJI Mic 2 能在发射器里存 8GB 32-bit float 备份，Mic Mini 没有这层保险——**一旦无线链路断开或接收器掉电，这一段的音频就真丢了**，没有本地兜底。
- 应对三招：① Osmo 用户直接用 OsmoAudio 直连，音频走设备本体记录；② 相机用户用 3.5mm TRS 把音轨录进相机，双保险；③ 纯手机直播走蓝牙直连，音轨在手机端。关键场次务必「无线 + 有线 / 直连」二选一兜底，别只信无线。

## 选购与验机

### 优缺点与适用人群

- **优点**：10g 近乎无感佩戴；开盖即连、上手零门槛；两档降噪 + 自动限幅 + 安全轨够用；蓝牙直连手机、OsmoAudio 生态联动是独门便利；¥999 两发一收含盒性价比高；48h 整机续航 + 快充。
- **短板**：**无内录，无线断连即丢音**；发射器本体即麦、不能换领夹头；塑料感强、抗造性一般；降噪是「两档」而非 Mic 2 的智能算法，极端噪声环境处理上限更低；无触屏、无独立监听口。
- **适合**：手机 / Osmo 出镜 Vlog、口播、直播、轻量访谈、旅行随拍——追求轻便与低门槛的创作者。
- **不适合**：棚拍、重要采访 / 活动跟拍、需要内录兜底的高可靠采集；这类请直接上 DJI Mic 2 或带内录的机型。延伸可看[麦克风与收音设备](/contents/设备/选型方法/麦克风与收音设备.md)的五方案选型矩阵。

### 二手行情与验机

当前为在售现役机型，二手以「拆封 / 99 新 / 单发射器补买」为主，价格随官方定价波动，以各平台实时为准；官方渠道购买仍是最稳选择。

| 验机项 | 检查要点 |
| --- | --- |
| 1. 配对与连接 | 开盖是否能自动配对；接收器插相机 / 手机是否被识别；蓝牙直连手机是否稳定 |
| 2. 收音实测 | 录一段人声，对比降噪强 / 弱 / 关三档差异；开自动限幅对着大音量说话看是否防爆 |
| 3. 传输稳定性 | 走开几米 / 隔一堵墙试有无卡顿、断连、爆裂音 |
| 4. 电池健康 | 发射器满电看是否还能接近 11.5h；充电盒补电次数是否明显下降 |
| 5. 接口与配件 | USB-C 充放电接触良好；磁吸片、夹持、防风毛套、3.5mm 线、转接头齐全 |
| 6. 固件 | DJI 官方 App 可读取固件版本，建议升到最新以修已知问题 |

## 使用体验与自查

### 使用体验速记

> 以下为通用长期使用观察，建议按你的真实体验校订。

- 出镜 Vlog 几乎忘记它在身上：10g + 磁吸，外套 / T 恤领口都不坠。
- 开盖即连是真的省心，但第一次用要记得「接收器要开机、手机蓝牙直连要手动配对一次」。
- 户外风大时，强档降噪 + 毛套 + 低切三者叠加，人声清晰度提升明显。
- 最怕的坑是「只走无线」——有次接收器没插牢，一段口播静音，从此重要场次一定用相机 3.5mm 兜底。

### 自查与常见误区

- **误区：无线稳定就万事大吉** → 它没有内录，无线一断就丢音；关键场次必须有线 / 直连兜底。
- **误区：降噪越强越好** → 室内安静环境开强档会吃掉人声细节，弱档更自然。
- **自查：开录前看接收器指示灯** → 确认已连上对应发射器、电量充足，再开拍。
- **自查：手机蓝牙直连时关掉其他蓝牙音频** → 避免系统把 Mic Mini 当耳机而不是麦克风。
- **延伸**：多机位 / 双人访谈看[麦克风与收音设备](/contents/设备/选型方法/麦克风与收音设备.md)；相机侧录音设置见[摄影 · 器材](/contents/摄影/器材/相机机身.md)的音频相关章节。
