## 定位与操控

### 定位与产品线坐标

Mini 2 是 DJI "免注册便携航拍" 档的奠基机型：把上代 Mavic Mini 的增强 Wi-Fi 直接换成旗舰级 OcuSync 2.0，续航与抗风也同步提升，是很多人入门无人机的首选。它和后来的 Mini SE / Mini 3 形成清晰的代际：

| 维度 | DJI Mini 2 | DJI Mini SE | DJI Mini 3 | DJI Mini 4 Pro |
| --- | --- | --- | --- | --- |
| 发布 | 2020-11 | 2021 | 2022 | 2023 |
| 重量 | 242g | 249g | <249g | <249g |
| 传感器 | 1/2.3" | 1/2.3" | 1/1.3" | 1/1.3" |
| 视频 | 4K/30 | 2.7K/30 | 4K/30（竖拍） | 4K/60 + HDR |
| 图传 | O2 / 10km | 增强 Wi-Fi | O3 / 10km | O4 / 20km |
| 避障 | 仅下视 | 仅下视 | 仅下视 | 全向（4 向） |
| 续航 | 31 min | 30 min | 51 min（智能电池 Plus） | 34–45 min |
| 特色 | 入门均衡 | 极致性价比 | 无损竖拍 | 全向避障 + 长焦 |

结论：要**便宜 + 三轴 + 4K + 长图传**的入门练手机，Mini 2 仍是二手市场的高性价比之选；要竖拍 / 大底 / 全向避障，往 Mini 3 / Mini 4 Pro 走。

### 机身与操控

- **轻与小**：242g 折叠后比手机大一点，塞进随身包无压力，且多数国家/地区 <249g 免实名登记（中国境内 250g 以上才需 CAAC 实名，Mini 2 通常免）。
- **遥控器**：标配 RC-N1 遥控器（手机夹屏 + 摇杆），支持 USB-C / Lightning / Micro-USB 三转接线，不挑手机；折叠收纳带保护锁扣。
- **App 与飞行**：DJI Fly App 负责激活、图传、航线与剪辑；内置**智能跟随 4.0**、**一键短片**（冲天 / 渐远 / 环绕 / 螺旋 / 彗星等）、**焦点跟随**、**航点飞行**（固定路线），新手也能出片。
- **起降与定位**：下视双目视觉 + 红外实现视觉悬停与返航；支持一键起飞 / 智能返航（低电量 / 失联自动回）。注意：无前 / 后避障，复杂环境靠飞手判断。

## 成像与飞行性能

### 相机与拍摄能力

- **画质基底**：1/2.3" CMOS + 1200 万像素，日光下色彩与解析符合消费级航拍预期；暗光（黄昏 / 夜景）小底天花板明显，别和手机旗舰夜景比。
- **视频规格**：4K/30fps（100 Mbps）为主流规格，2.7K/60、1080p/60 给慢动作与后期裁切留空间；编码 MP4(H.264)，兼容性好、剪辑门槛低。
- **变焦**：4K 下 2×、2.7K/1080p 下 4× 数字变焦，远摄构图方便但为数码裁切，**画质随倍数下降**，重要镜头尽量飞近拍。
- **云台**：三轴机械增稳是 Mini 2 相对上代最大提升之一，飞行抖动 / 风里成片依然平稳；俯仰可控，适合低空掠过 / 环绕运镜。
- **色彩与后期**：JPEG + DNG RAW 双格式，RAW 给调色留空间；**无内置 Log 预设**（消费级定位），风格化靠后期，宽容度有限。

### 图传、避障与飞行性能

- **图传**：OcuSync 2.0 抗干扰远强于上代 Wi-Fi，FCC 下最远 10 km、实时 720p/30fps 画面；实际请遵守当地法规、尽量视距内飞行。
- **避障**：**仅下视视觉定位**，无主动前向 / 后向避障。这意味着它不会"自己躲树"——穿林 / 贴墙 / 低空掠水全靠飞手。新手务必在空旷场地练手。
- **续航与抗风**：标称 31 分钟（理想环境），实际含起降 / 风耗约 20–25 分钟可用；最大抗风 5 级（约 8.5–10.5 m/s），海边 / 高原风大时留足返航电量。
- **速度与海拔**：运动模式水平 16 m/s，普通 / 平稳档更慢更稳；最大起飞海拔 4000 m，高海拔动力下降明显，注意电池与返航余量。

## 配件与生态

Mini 2 的体验很大程度由配件决定，尤其续航与便携：

- **智能飞行电池**：2250 mAh / 17.32 Wh，单块 31 分钟；**充电管家**可顺序充 3 块，外拍必入。
- **畅飞套装**：多 2 块电池 + 充电管家 + 全向桨叶保护罩 + 单肩包，比单买划算，是多数人的首选。
- **桨叶保护罩**：全向包覆桨叶，室内 / 新手 / 儿童旁飞行显著提升安全；但会略增重、降一点机动。
- **ND 滤镜**：航拍常用 ND 减光（ND16/64/256）压快门拍丝滑流水 / 云， daylight 强光下控制曝光。
- **收纳**：折叠后很小，原厂迷你包或第三方硬壳收纳盒都能装；转接线 / 备用摇杆 / 螺丝刀随箱带齐。
- **选购提醒**：务必用官方电池；非官方电池可能导致异常、且不在保修范围。

## 选购与验机

### 优缺点与适用人群

**优点**

- <249g 免注册（多数地区），随身无负担，说飞就飞。
- 三轴机械云台 + 4K/30 + OcuSync 2.0 长图传，入门档配置均衡。
- 智能跟随 / 一键短片 / 航点飞行，新手也能稳定出片。
- 二手性价比高（停产但存量大），练手成本低。

**短板**

- 仅下视定位、**无主动避障**，复杂环境风险全在飞手。
- 1/2.3" 小底，暗光 / 夜景画质有限；无 Log，调色空间小。
- 数码变焦画质随倍数掉，远摄靠"飞近"而非"拉焦"。
- 续航理想 31 分钟、实际约 20–25 分钟可用，长线航拍需多备电池。

**适用**：旅行 / 风光航拍、Vlog 空镜、房产 / 活动记录、新手练手、轻装徒步随拍。
**不适用**：复杂树林 / 城市楼群穿飞、暗光夜景航拍、需要全向避障的安全敏感场景、长焦远摄打鸟 / 赛事。

### 二手行情与验机

> 行情为 2026-08 参考区间，Mini 2 已停产，二手存量大、价格走低；优先成色好 + 电池健康的单机 / 畅飞套装。

| 验机项 | 步骤 | 风险点 |
| --- | --- | --- |
| 外观与桨叶 | 看机身划痕、桨叶有无裂痕 / 变形 | 摔机痕迹 = 云台 / 电机潜在损伤 |
| 电机与云台 | 上电自检，看四轴转动是否异响、云台归位是否卡顿 | 云台抖 / 歪 = 撞击后遗症 |
| 电池健康 | 满电实飞计时，看是否明显短于 25 分钟可用 | 鼓包 / 掉电快 = 老化，电池贵且难配 |
| 图传与 GPS | 空旷处连 DJI Fly，看 720p 画面与卫星数（≥10 颗） | 图传断连 / 搜星慢 = 天线或主板问题 |
| 功能自检 | 飞一段 4K、开智能跟随 / 一键短片、试自动返航 | 避障缺失下更依赖这些功能正常 |
| 配件齐整 | 遥控器转接线 / 备用摇杆 / 螺丝刀 / 桨叶罩是否原装 | 缺充电管家续航腰斩 |

> 避坑：低于 ¥1000 的"99 新单机"多为摔机翻新或电池衰竭；SN 与 App 绑定 / 激活日期不符慎入；进水机 / 摔机云台歪的再便宜也别碰。

## 使用体验与自查

### 使用体验速记

> 以下为通用长期使用观察代拟，待你按真实体验校订。

- 便携：折叠塞包就走，旅行掏出来 1 分钟起飞，是它最爽的点。
- 出片：三轴云台 + 一键短片，新手第一段环绕 / 渐远就能发朋友圈。
- 续航：实际 20 多分钟，出门必带畅飞套装 3 电 + 管家，否则拍不尽兴。
- 画质：白天惊喜、暗光别指望；无 Log 后期空间有限但 RAW 够修。
- 槽点：无避障，第一次树林穿飞手心出汗；变焦数码味重，远摄靠飞近。

### 自查与常见误区

- **误区：有"避障"能自己躲**。Mini 2 仅下视定位，**无前后主动避障**，不会自动绕障；穿林贴墙全靠你。
- **误区：4× 变焦等于长焦镜头**。那是数码裁切，画质随倍数掉；重要镜头飞近拍，别指望拉焦。
- **误区：31 分钟能飞满**。理想值，含风耗 / 起降实际 20–25 分钟，留 20% 以上返航余量。
- **误区：<249g 全球免管**。多数地区免注册，但飞行仍受空域 / 禁飞区 / 视距规定约束，出发前查当地法规与 App 限飞区。
- **自查**：起飞前校准指南针（换场地）、看 GPS 星数、查螺旋桨有无裂、电池电量与桨叶罩是否取下、确认返航点与限飞区。

> **延伸**：航拍入门与合规飞行见[设备 · 选型方法 / 无人机与稳定器](选型方法/无人机与稳定器.md)；运镜与空镜思路可回[摄像 · 短视频脚本](../摄像/短视频/短视频脚本.md)；配件认准 DJI 官方渠道，不链第三方拆机电池。
