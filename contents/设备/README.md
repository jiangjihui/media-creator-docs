## 单品档案规范

为保证"随用随补"不走样，新档案遵循以下约定：

- **命名与归档路径**：`单品档案/<类型>/品牌-型号.md`（如 `单品档案/相机/SONY-A6400.md`）；侧栏显示文本用中文习惯名（如「索尼 A6400」）。现有类型：相机 / 摄像机 / 运动相机与无人机 / 镜头 / 灯光 / 音频 / 支撑与稳定。
- **模板变体**：胶片机、DV 机等新品类允许裁剪章节（如去掉"视频能力 / 对焦与连拍"），但必须保留三段内核——客观规格、使用体验、二手行情与验机。
- **固定章节结构**：
  1. 顶部 blockquote：定位声明（客观为主 + 个人体验补充）+ **信息核对时点**
  2. 规格速览表
  3. 定位与产品线坐标（同期竞品对比）
  4. 机身与操控
  5. 对焦与连拍表现
  6. 视频能力详述
  7. 镜头群与配件生态
  8. 优缺点清单 → 适用 / 不适用人群
  9. 二手行情与验机避坑（步骤表格化）
  10. 使用体验速记
  11. 自查清单 / 常见误区 / 延伸
- **单一事实源**：画幅、曝光等原理只链接到[摄影 · 器材](../摄影/器材/相机机身.md)，不在本栏目重复展开；本栏目独有的型号参数也不回写摄影栏。
